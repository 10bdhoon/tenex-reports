  • 🚨 CRITICAL exec security=full 활성화 — 카리나 에이전트

    카리나 에이전트에 exec security="full"이 설정되어 있어 모든 쉘 명령을 승인 없이 실행할 수 있습니다. 이는 악의적 프롬프트나 환경 오염 시 시스템 전체를 위협할 수 있는 최고 위험 설정입니다.

    ✅ 권장 조치: security="full" → security="allowlist"로 변경 후 허용 명령어 명시적 등록
  • 🚨 CRITICAL exec security=full 활성화 — 개실장 에이전트

    개실장(개발 총괄) 에이전트에 exec security="full"이 설정되어 있습니다. 개발/시스템/인프라 권한과 결합 시 피해 범위가 매우 클 수 있습니다.

    ✅ 권장 조치: 개발 관련 명령어만 allowlist에 등록, elevated 권한 최소화
  • 🚨 CRITICAL exec security=full 활성화 — 마실장 에이전트

    마케팅/광고 담당 마실장 에이전트에 exec security="full"이 설정되어 있습니다. 마케팅 도구 실행 범위를 넘는 권한이 부여된 상태입니다.

    ✅ 권장 조치: 마케팅 관련 API 호출만 허용하는 allowlist로 교체
  • 🚨 CRITICAL exec security=full 활성화 — 고실장 에이전트

    고객/CS 담당 고실장 에이전트에 exec security="full"이 설정되어 있습니다. CS 업무에는 시스템 명령 실행이 불필요하므로 과도한 권한입니다.

    ✅ 권장 조치: CS 에이전트는 exec 권한 제거 또는 deny 설정 권장
  • 🚨 CRITICAL exec security=full 활성화 — 콘실장 에이전트

    콘텐츠/채널 담당 콘실장 에이전트에 exec security="full"이 설정되어 있습니다. 콘텐츠 작성 에이전트에 대한 무제한 실행 권한은 과도한 설정입니다.

    ✅ 권장 조치: 콘텐츠 게시/조회 관련 명령만 포함하는 allowlist 적용
  • 🚨 CRITICAL Open groupPolicy with elevated tools — 전역 설정

    groupPolicy="open"이 설정된 상태에서 elevated 권한 도구가 활성화되어 있습니다. 인증되지 않은 사용자도 elevated 도구에 접근 가능한 상태입니다.

    ✅ 권장 조치: groupPolicy를 "allowlist"로 변경하고 허용 사용자 명시적 등록
  • 🚨 CRITICAL elevated 권한 미승인 실행 위험 — 복합 위험

    open groupPolicy + exec security=full 조합으로 인해 외부 채널(Slack DM 등)로 들어오는 임의 명령이 시스템에서 무제한 실행될 수 있습니다.

    ✅ 권장 조치: 채널 allowlist 설정 + 명령 승인 플로우 도입
  • 🚨 CRITICAL API 키 환경 변수 노출 위험 — 환경 설정

    exec security=full 환경에서 환경변수($CAFE24_TOKEN, $META_TOKEN 등)를 임의 명령으로 읽어낼 수 있는 위험이 있습니다. 토큰 탈취 경로가 열려 있는 상태입니다.

    ✅ 권장 조치: 환경변수 접근 제한 + 토큰 Vault 또는 macOS Keychain 이관
  • 🚨 CRITICAL OpenClaw Gateway 외부 노출 점검 필요 — 127.0.0.1:18789

    OpenClaw Gateway가 127.0.0.1:18789에서 실행 중입니다. 현재 로컬바인딩이나 Tailscale 경유 원격 접근 시 인증 우회 가능성을 점검해야 합니다.

    ✅ 권장 조치: Gateway 인증 토큰 주기적 갱신 + Tailscale ACL 정책 검토
  • ⚠️ WARN Slack groupPolicy="open" with no channel allowlist — Slack 플러그인

    Slack 플러그인의 groupPolicy가 "open"으로 설정되어 채널 allowlist가 없습니다. 워크스페이스의 모든 채널에서 봇에게 명령을 내릴 수 있는 상태입니다.

    ✅ 권장 조치: allowedChannels 목록에 운영 채널만 명시, 나머지 무시 처리
  • ⚠️ WARN Notion API DB 공유 미완료 — Notion Integration

    Notion Integration("Claude Assistant")에 태스크 관리 DB가 공유되지 않아 해당 DB 읽기/쓰기 작업이 실패할 수 있습니다.

    ✅ 권장 조치: Notion DB 페이지 → 공유 → Integration "Claude Assistant" 추가
  • ℹ️ INFO Cafe24 토큰 갱신 주기 60분 → 90분 불일치 — launchd 설정

    Cafe24 API 토큰의 공식 만료 시간은 60분이나, launchd 갱신 주기가 90분으로 설정되어 짧은 시간 토큰이 만료 상태일 수 있습니다. 현재 운영 영향은 미미합니다.

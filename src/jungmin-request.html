신규 / 재방문 세션 추이와
1차 분석 결론, 실행 체크리스트

스레드에서 논의된 신규·재방문 세션 추이, 전환율 해석, Cafe24 실주문 기준 모순, 그리고 이번 주 바로 실행할 체크리스트까지 한 페이지에 정리했습니다.

기간 고정: 최근 12주 동일 기간 원장: Cafe24 진단용: GA4 / DataRize / Mixpanel

재방문 우위가 얼마나 보이는지 확인하기 위한 주차별 CVR 추이입니다.

확정 사실

  • 주차 평균 CVR은 신규 0.294%, 재방문 0.301%로 거의 같습니다.
  • 정상적이면 재방문 전환율이 신규보다 의미 있게 높아야 하는데, 현재는 우위가 거의 보이지 않습니다.
  • Cafe24 실주문 기준으로는 1월~3월 반복주문 비중이 대체로 60~72% 수준으로 높았습니다.
  • 즉, 실주문 구조상 기존고객 기여는 높은데 세션 CVR에서는 재방문 우위가 거의 안 보이는 모순이 있습니다.

가설 3개

  • 계측/분류 불일치: GA4 신규·재방문 세션과 Cafe24 실구매 기준이 어긋나 있을 가능성
  • 재방문 설득 구조 약함: 장바구니 리마인드, 후기/FAQ/비교표, 재방문 전용 오퍼가 약할 가능성
  • 고민형 재방문층 확대: 첫 방문에 살 사람은 바로 사고, 재방문은 오래 고민하는 층이 많이 섞일 가능성

가장 유력한 병목

가장 유력한 병목은 장바구니 이탈 재방문자와 checkout 이탈 재방문자 구간이며, 현재는 이 구간의 세션 기준과 실구매 기준이 어긋나 있을 가능성이 큽니다.

장바구니 이탈 재방문자 checkout 이탈 재방문자 결제/CRM/오퍼 병목 우선 검증

숫자 충돌 주의 구간

세션 기준 신규/재방문은 브라우저, 기기, 쿠키 기준이고, Cafe24의 first_order / 반복주문은 실구매 이력 기준입니다. 따라서 두 숫자는 직접 1:1로 해석하면 오판 가능성이 큽니다. 특히 네이버페이, 외부브라우저, 기기 이동이 있으면 재방문 구매가 신규 세션처럼 섞여 보일 수 있습니다.

이번 주 즉시 실행안

1) 매칭률 / 불일치율 산출

  • GA4 세션 기준과 Cafe24 주문 기준의 매칭률 / 불일치율 산출
  • 신규 세션인데 Cafe24 반복주문인 비중
  • 재방문 세션인데 Cafe24 first_order인 비중

2) 병목 세그먼트 확인

  • 장바구니 이탈 재방문자 병목 확인
  • checkout 이탈 재방문자 병목 확인
  • 어느 단계에서 신규 대비 우위가 사라지는지 확인

3) 메시지/랜딩 분리

  • 재방문 전용 메시지 / 랜딩 분리
  • 후기 / FAQ / 비교표 / 결제 불안 제거 강화
  • 재방문 전용 오퍼 테스트

실행 체크리스트

GA4

  • 어디서: 보고서 또는 탐색(Explore) > 자유 형식 / 퍼널 탐색
  • 뭘 뽑고: 신규/재방문 퍼널, 채널별, 디바이스별, 랜딩별, 장바구니/checkout 재방문 세그먼트
  • 어떻게 비교: 최근 12주 동일 기간 기준, 신규 대비 재방문 우위가 어느 단계에서 사라지는지 확인

DataRize

  • 어디서: 세그먼트 / 자동화 캠페인 / 메시지 성과 리포트
  • 뭘 뽑고: 장바구니 이탈, checkout 이탈, 상세 2회 이상, 24시간 내 재방문, 기존 구매자, CRM 유입 재방문자
  • 어떻게 비교: 발송수, 오픈율, 클릭률, 구매전환율, 매출기여로 병목 위치 판정

Cafe24

  • 어디서: 관리자 또는 API 주문 데이터
  • 뭘 뽑고: first_order, 반복주문, 결제수단, 상품별 첫구매/재구매, 주차별 repeat order 비중
  • 어떻게 비교: 네이버페이 / 직접결제 기준 불일치율 차이 확인

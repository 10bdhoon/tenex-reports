루틴 추천 로직 (통증 점수별)
통증 점수전략🏃 운동♻️ 회복🦴 교정AI 멘트
8~10점 심함회복 최우선아주 가벼운 이완 2~3분WS-200 20분 → ES-808 약하게 10분생략 or CS-25 1단계 5분만"통증이 심해요. 오늘은 충분히 쉬어드릴게요."
5~7점 중간회복 → 교정기본 스트레칭 5분WS-200 15분 → ES-808 보통 강도 10분CS-25 1~2단계 10분"회복 먼저 하고, 가볍게 교정을 시작해요."
1~4점 낮음풀 루틴1분도수 루틴 5~10분WS-200 10분 → ES-808 보통 10분CS-25 2~3단계 15분"컨디션 좋아요! 오늘 루틴 완성해봐요. 💪"
고정 순서: 깊은 이완 (WS-200) → 정확한 부위 전기자극 (ES-808) → 붙은 디스크 교정 (CS-25)
기기 없으면: 해당 스텝 → 영상 + 제품 소개로 자동 대체

Day 1 — 프로젝트 세팅
  • Expo + TypeScript 초기화
  • Supabase 신규 프로젝트 + DB 테이블 생성
  • 카카오 로그인 연동
  • 3탭 네비게이션 구조

  • 3단계 온보딩 (부위·통증·기기)
  • 사용자 프로필 Supabase 저장

Day 3 — 홈 탭 (핵심)
  • 통증 점수 입력 UI (큰 슬라이더)
  • 루틴 추천 로직 (점수별 분기)
  • 기기 없을 때 → 영상 + 제품 소개 로직
  • AI 코치 멘트 (규칙 기반)
Day 4 — 회복 기록 탭
  • 통증 점수 히스토리 그래프
  • 주간 루틴 달성 달력
  • 연속 달성 카운터
Day 5 — 마이 탭 + 푸시
  • 프로필 + 기기 설정
  • 스토어 링크 연결
  • 푸시 알림 (7시/19시/22시)
Day 6 — QA + 버그 픽스
  • 전체 플로우 QA (실제 클릭 테스트)
  • iOS/Android 디바이스 확인
  • 엣지 케이스 처리
Day 7 — 빌드 + 배포
  • EAS Build 제출
  • TestFlight (iOS) 내부 테스트
  • 피드백 수집 → 즉시 수정

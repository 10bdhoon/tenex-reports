Lv3. 실전 자동화 · 보안 · 멀티에이전트
STEP 01. 자동화 엔진 — 크론잡 · 하트비트 · 웹훅
⏰ 크론잡 = 알람시계 — 정해진 시간에 실행 (매일 07:00 매출 리포트)
💓 하트비트 = 심장박동 — 30분마다 HEARTBEAT.md 확인, 할 일 있으면 실행
🔔 웹훅 = 외부 트리거 — 주문 들어오면 → 에이전트 즉시 깨어남
방식트리거정확도비용
크론잡정해진 시간정확실행 시만
하트비트주기적 체크느슨매번 API콜
웹훅외부 이벤트즉시이벤트 시만
✅ 우리 사례: daily-report 크론잡, HEARTBEAT.md 체크리스트
STEP 02. 보안 하드닝
🔒 Gateway 보안 — TLS 암호화, bind 127.0.0.1, 토큰 인증
🛡️ 에이전트 권한 — 도구 정책, exec allowlist (node/curl/git만)
🔑 API 키 관리 — TOOLS.md 직접 노출 위험 → .env / 키체인 사용
🔍 보안 감사 — openclaw security audit
⚠️ 현재 상태: 와일드카드(*) 권한 = Critical
STEP 03. 멀티에이전트 — AI 팀 빌딩
📁 에이전트별 SOUL.md / AGENTS.md / MEMORY.md 분리
🎯 우리 구조 — 카리나(CEO비서) → 데이터봇 / 마케터봇 / 개발봇
🔄 협업 패턴 — 크론잡 → 데이터봇 → 분석 → 카리나 → 태훈 보고
🚦 폭주 방지 — 일일 실행 횟수 제한, 비용 상한, 타임아웃, 이벤트 기반 + 2인1조

핵심: 크론잡은 정확한 스케줄, 하트비트는 유연한 주기 체크, 웹훅은 즉각 반응. 세 가지를 조합하면 잠자는 동안에도 돌아가는 자동화 팀이 완성됨. 단, 보안은 출발점부터 — 와일드카드(*) 권한은 즉시 제거 대상.

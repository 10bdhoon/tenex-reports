✅ 확정 수정 반영 사항 (최종 확정 8건)
  • 1
    데이터 수집 설계 추가 VAS 추이 + 운동 완료율 + 이탈 지점 + 기기 사용 여부별 세그먼트 4축 설계 포함
  • 2
    주차별 콘텐츠 — MVP = 1주차만 기존 동연님 숏폼 재활용 + 부족분 신규 촬영
  • 3
    확장 구조 — Q0 부위 선택 자리 확보 온보딩에 "부위 선택" Q0 비워둠. 목 → 어깨 → 허리 순 확장 예정
  • 4
    무료 유저 전환 팝업 "기기 유저는 평균 2주 더 빨리 회복" + 비교 그래프. 운동 완료 후 노출
  • 5
    개인 변화 페이지 — "나의 회복 여정" VAS 추이 그래프 + 운동 일수 + 1분도수님 한마디 포함
  • 6
    CS-25 크로스셀링 수정 "취침 모드 예약" → "취침 전 견인 케어". 베고 자는 용도 아님. 자기 전 10분 디스크 견인 용도로 명확화
  • 7
    리텐션 장치 — 푸시 알림 + 연속 출석 + 주간 리포트 주간 리포트에 1분도수님 격려 한마디 포함
  • 8
    강등 시 UX 메시지 확정 "오늘은 몸이 좀 힘든 날이에요. 무리하지 말고 가장 안전한 운동으로 바꿔드릴게요" 팝업

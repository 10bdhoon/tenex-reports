TENOS MVP 구현 계획

이 페이지는 더 이상 개념 설명이 아니라, TENOS 자체 엔진 MVP를 실제로 만들기 위한 구현 계획이다. 목표는 OpenClaw 전체 복제가 아니라, 입력 수신 → memory 주입 → 라우팅 → worker 실행 → 보고 → 저장까지 테넥스 전용 최소 실행 루프를 독립적으로 굴리는 것이다.

목표: 독립 루프 1개 완성
범위: Router + Memory + State + Worker + Report
원칙: 문서보다 실행 우선

1. MVP 완료 기준

완료 정의: 메시지 1개가 들어오면, TENOS가 관련 memory를 붙이고, 담당 리드를 정하고, 필요시 worker를 실행하고, 결과를 요약해서 보고한 뒤, 최종 결과를 상태/기억층에 저장하면 MVP 1차 완료다.

2. 코어 모듈 5개

Core 1

Input Router

텔레그램/슬랙/내부 이벤트를 공통 envelope로 변환.

  • eventType
  • source channel
  • request payload
Core 2

Memory Layer

brain.db, MEMORY, daily memory, HEARTBEAT를 불러와 필요한 만큼만 주입.

  • search
  • context assembly
  • result save
Core 3

State Store

작업 상태, 담당자, 마지막 업데이트, 승인대기 여부를 추적.

  • task id
  • owner
  • status
Core 4

Worker Runtime

필요한 경우에만 워커를 실행하고 timeout, retry, result capture를 처리.

  • spawn
  • collect
  • retry
Core 5

Report Loop

결과를 카리나/리드 요약 형태로 정리하고 최종 저장까지 닫는다.

  • summary
  • approval hold
  • save

3. 실제 구현 순서

순서구현 항목완료 조건
Step 1Event Envelope 스키마 정의모든 입력이 같은 JSON 구조로 정리됨
Step 2Memory Loader / Context Assembler요청 타입별 memory 조립 규칙 고정
Step 3Lead Router카리나 직접 처리 vs 실장 위임 결정 가능
Step 4Task State Store작업 생성/진행/완료 상태 추적 가능
Step 5Worker Executor세부 실행 유닛 호출 후 결과 회수 가능
Step 6Report + Save Loop보고 후 brain.db/상태 저장까지 자동 수행

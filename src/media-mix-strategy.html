어트리뷰션 모델

🎯 라스트클릭 어트리뷰션

마지막으로 클릭한 채널에 전환 100% 기여. 단순하고 설정이 쉬우나 브랜딩/인지 채널(유튜브, 틱톡)의 기여가 과소평가됨. 메타 단일 채널 운영 시 현재 방식으로 충분하나, 멀티채널 확장 시 판단 왜곡 발생.

현재 방식
단순 분석

🔀 멀티터치 어트리뷰션

구매 경로의 모든 터치포인트에 기여도 배분 (Linear, Time Decay, Data-Driven 방식). 유튜브로 인지 → 네이버로 검색 → 메타 리타겟팅 → 구매 경로의 실제 기여 측정 가능. UTM + Mixpanel + 카페24 교차검증으로 구현. 멀티채널 전환 시 필수.

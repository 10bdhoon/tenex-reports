TENEX Partnership OS Guide

이 페이지는 Partnership OS의 전체 기능, 사용 순서, 현재 자동화 범위와 사람 검토 범위를 설명하는 가이드다.

실행 화면 바로가기 메인 리포트로 가기

1. 이 툴이 하는 일

  • 인스타 크리에이터를 DB처럼 누적 관리
  • 팔로워보다 실제 반응이 좋은 계정을 선별
  • 1차 DM 대상을 정리하고, 후속 검토 큐까지 관리
  • 영상 업로드 링크, 성과, 추천코드/공동구매 상태를 한 화면에서 추적

  • 1차 DM Queue 관리
  • 후속 검토 큐 상태 저장

  • 공동구매 여부 최종 판단
  • 콘텐츠 성과 수동 입력 및 품질 판단

4. 추천 사용 순서

  1. Instagram Creator DB에서 계정 검색/정렬
  2. Priority Candidates와 1차 DM Queue 확인
  3. 1차 DM 발송 대상 결정
  4. 답장 오면 Human Review Inbox에서 검토
  5. 후속 검토 큐로 넘기고 다음 액션 처리
  6. 콘텐츠 업로드 링크와 성과를 기록
  7. 추천코드/공동구매 상태를 갱신

5. 현재 제한사항

  • 실제 Instagram 1차 DM 발송은 아직 UI 중심, 실계정 연동 미완
  • 답장 자동 수집 미완, 현재는 구조와 저장 흐름만 있음
  • 콘텐츠 성과는 수동 입력 중심
  • 추천코드/공동구매 실매출 자동 연동은 아직 안 붙음

6. 앞으로 붙을 것

  • 실제 1차 DM 발송 연동
  • 실제 답장/후속 반자동 수집
  • 추천코드/공동구매 실적 자동 연동
  • 저장 성공/실패 피드백 고도화

TENOS Event Flow

TENOS Event Flow는 “어떤 입력이 들어오면 누가 받고, memory는 언제 검색되며, 누가 worker를 띄우고, 어디서 승인하고, 어떤 경로로 보고되고, 언제 저장되는가”를 정의하는 흐름 레이어다. 즉 TENOS의 실제 작동 순서를 시각화한 페이지다.

질문: 어떤 입력이 오면 누가 처리하나?
질문: worker는 언제 spawn되나?
질문: 보고와 저장은 어디서 일어나나?

1. 가장 기본 흐름

Step 1
입력 수신
태훈 메시지, 슬랙 멘션, 크론 이벤트, 웹훅 등.
  • Telegram
  • Slack
  • cron
  • webhook
Step 2
이벤트 분류
무슨 종류의 요청인지 라벨링.
  • user_message
  • manager_task
  • cron_tick
  • alert
Step 3
Memory 검색
관련 기억이 있는지 먼저 확인.
  • brain.db
  • MEMORY
  • HEARTBEAT
Step 4
리드 분배
카리나가 직접 할지, 실장에게 넘길지 결정.
  • 카리나
  • 마실장
  • 개실장
  • 고실장 / 콘실장
Step 5
worker 실행
필요한 경우에만 세부 실행 worker를 띄움.
  • 조사
  • 분석
  • 코드
  • 콘텐츠 초안
Step 6
검수 / 보고 / 저장
카리나 요약, 승인, 최종 보고, memory 저장.
  • 태훈 보고
  • 승인 게이트
  • 결과 저장

2. 입력 종류별 흐름 차이

입력 종류예시기본 흐름
User Message“광고 분석해줘”입력 수신 → memory 검색 → 카리나 분배 → 실장/worker → 카리나 요약 → 태훈 보고 → 저장
Manager Task실장이 다른 팀원 실행 필요 판단실장 컨텍스트 유지 → worker spawn → 결과 검수 → 카리나 경유 보고
Cron Tick정시 보고, 리마인더, 수집스케줄 이벤트 → 관련 실장/카리나 실행 → 필요시 알림 → 저장
Alert매출 급감, 수집 실패이상값 감지 → 관련 리드 호출 → 원인 확인 → 태훈 알림 → 저장

3. 카리나와 실장의 역할 분기

카리나 직접

카리나가 직접 처리할 때

전략 판단, 우선순위 조정, 단순 응답, 실장 배분, 최종 보고, 승인/리스크 판단처럼 상위 레이어 일은 카리나가 담당.

실장 위임

실장에게 넘길 때

마케팅, 개발, 콘텐츠, 고객성공처럼 기능별 실행이 필요한 요청은 해당 실장에게 위임.

4. worker는 언제 spawn되나

spawn 필요

큰 조사 / 분석

실장이 직접 끝내기보다 세부 실행이 필요한 경우.

spawn 필요

코드 / 자료 생성

개발, 콘텐츠 초안, 데이터 가공처럼 실제 산출물이 필요한 경우.

spawn 불필요

단순 판단 / 답변

카리나 또는 실장 레벨에서 바로 판단 가능한 경우 worker 없이 끝낸다.

5. 승인 게이트는 어디에 있나

승인은 마지막이 아니라 중간에 걸린다.
즉 결과물이 나왔다고 바로 태훈에게 전달하거나 실행하는 게 아니라, 광고 변경, 배포, 고객대면, 민감 작업은 중간에서 멈추고 카리나/태훈 승인 후 다음 단계로 간다.
민감 작업

중간 승인 필요

광고 ON/OFF, 예산 변경, 운영 리스크, 고객대면 발화, 배포/설정 변경.

비민감 작업

바로 보고 가능

요약, 분석, 리서치 초안, 내부 운영 정리처럼 실행이 동반되지 않는 결과물.

6. 보고는 어떻게 닫히나

단계무엇이 일어나는가
worker 완료세부 실행 결과를 실장에게 반환
실장 검수기획 의도와 맞는지 확인, 부족하면 재실행
카리나 통합실장 결과를 최종 사용자 언어로 요약
태훈 보고필요한 결정 포인트 포함해서 전달
기록 저장brain.db, daily memory, HEARTBEAT에 필요한 부분 반영

7. Event Flow에서 흔들리면 안 되는 원칙

원칙 1

카리나가 최종 허브다

실장끼리 바로 사용자에게 붙지 않는다. 최종 보고 허브는 카리나다.

원칙 2

실장은 판단, worker는 실행

실장이 직접 실무에 빠지면 구조가 무너진다.

원칙 3

기록 저장까지가 완료다

보고만 하고 저장 안 하면 시스템은 학습되지 않는다.

⚠️ 핵심 결론

어떤 플랫폼의 공식 API로도 "콜드 DM 자동 발송"은 불가능하다.
인플루언서 검색은 YouTube API만 제대로 되고, 나머지는 제한적이다.
스미스 멘토의 "공식 API 쓰면 되잖아" 발언은 API 기능을 오해한 것이다.

📸
Instagram Graph APIMeta 공식
인플루언서 검색 (카테고리별)
  • Business Discovery API: username을 이미 알아야만 조회 가능
  • Hashtag Search: 게시물 ID만 반환, 계정 목록 추출 불가 (rate limit + 권한)
  • "물리치료사 1000명 리스트" API로 뽑기 = 불가능
❌ 불가
DM 자동 발송 (콜드 아웃리치)
  • Send API는 IGSID(수신자 ID) 필수 — 상대방이 먼저 DM 보냈을 때만 생성됨
  • 내가 먼저 DM 보내는 것(콜드) = API 구조상 원천 불가
  • 설령 IGSID 있어도 메시지 창은 24시간만 유효
❌ 절대불가
인바운드 메시지 응답 자동화
  • 내 계정에 먼저 DM 보낸 사람에게 자동 응답 가능
  • 단, 이건 아웃리치가 아님 (기존 팔로워 응대용)
✅ 가능
계정 데이터 수집 (팔로워/참여율)
  • Business Discovery API: followers_count, like_count, comments_count 등
  • 단, username을 이미 알고 있어야 함
  • Advanced Access: App Review + Business Verification 필요
△ 제한적
항목내용
API 비용무료
기본 요건Instagram Professional Account
Rate Limit4,800 × 지난 24h Impressions 수 calls/일
🎵
TikTok Research APITikTok Developers
인플루언서 검색 (카테고리별)
  • 비디오 검색 API로 해시태그+지역 필터 가능 (쿼리당 최대 100건)
  • 영상 → creator_username 추출 → 크리에이터 목록 구성 (우회 가능)
  • Research API 승인 조건: 학술/연구 목적. 마케팅 용도 승인 불투명
△ 조건부 가능
DM 자동 발송
  • TikTok 공식 API 제품군에 DM 기능 자체가 없음
  • Research API는 읽기 전용(read-only)
  • Login Kit, Share Kit, Content Posting API — 모두 DM 없음
❌ API 없음
계정 데이터 수집
  • follower_count, likes_count, video_count, bio_description 등
  • username을 알아야만 계정 조회 가능 (Research API 승인 후)
△ 승인 필요
항목내용
API 비용무료
승인 필요Research API 별도 신청 + 심사 (학술 목적 중심)
▶️
YouTube Data API v3Google
채널 검색 (키워드/카테고리)
  • q=물리치료사 &type=channel ®ionCode=KR &relevanceLanguage=ko
  • 한 번에 최대 50개, pageToken으로 페이징
  • 세 플랫폼 중 유일하게 제대로 되는 검색
✅ 완전 가능
채널 상세 데이터 수집
  • subscriberCount, videoCount, viewCount, description (이메일 파싱 가능)
  • 단, 구독자 수는 1000단위 반올림 (2019년부터 YouTube 정책)
✅ 가능
DM 자동 발송
  • YouTube에는 DM 기능 자체가 없음 (API도 없음)
  • 댓글 작성(commentThreads.insert)은 가능하나 스팸 간주 + ToS 위반 리스크
❌ DM 없음
항목내용
API 비용무료 (10,000 units/일 기본)
검색 비용100 units/회 → 하루 100회 검색 가능
실용 계산채널 500개 수집 = 약 1,500 units → 하루 안에 완료

1 게시판 최종안

기존 좋은 구조 유지 + 4주차 핵심 구멍 3개 메우기

신생 카페라 게시판은 압축해서 시작한다. 부위 세분은 게시판이 아니라 말머리로.

유지하는 좋은 구조

  • [필독] 5가지 약속 — "필독공지 = 수익모델" 자리. 1분도수/키네메디칼 입점 리드를 세계관으로 심는다(제품 도배 아님, 세계관).
  • 가입인사(회복선언) — 글쓰기 전 통과의례. 동질감·소속감을 만드는 진입 게이트.
  • [치료 경험담] 3종 — 보존치료담 / 병원치료담 / 수술담. 인정욕구 엔진(자랑·기여).

추가하는 3개 (4주차 핵심 구멍)

  • [오늘의 회복] 매일 인증 게시판 NEW · 제일 큰 구멍 — 3종 인증 통합: ①진단샷(MRI/X-ray) ②오늘 1분도수 운동 ③회복 경과. 하루 15글 · 조회 1000+는 여기서 나온다.
  • [회복 코칭실] NEW · 상위등급 전용 — 도수치료사 심화 Q&A, 부위별 시크릿 운동법. 접근 제한이 곧 미끼(희소성).
  • [건강토론] NEW · 정상적 논쟁 — "디스크 수술 해야 하나", "보존치료 vs 도수" 등 열띤 토론 = 트래픽 콘텐츠.

3 리워드 설계 (네쇼라 3자 이득)

회원도 돈 버는 구조 — 등급 리워드 × 추천 커미션

등급 리워드에 정품등록 추천 시스템(추천코드 커미션)을 연결해, 광고주·회원·운영자가 모두 이득 보는 네쇼라 구조를 만든다.

회원이 얻는 것

회복(즉각 시원함) + 인정(댓글·등업) + 리워드(제품 증정) + 추천코드 커미션(회원도 돈 번다).

우리(키네/1분도수)가 얻는 것

제품 리드(코칭실·후기로 자연 노출) + 브랜드(회복 커뮤니티 권위) + CAC 절감(자가증식 UGC).

추천코드 = 시리얼 = 할인 3-in-1

  • 한 코드가 ①정품 시리얼 ②그 회원의 추천코드 ③친구가 쓰는 10% 할인쿠폰을 동시에 수행.
  • 포맷 KMES + 6자(총 10자, 하이픈 없음) — 예 KMESBXFF7M. 혼동문자(O·0·I·1·L) 제외.
  • 카페24 쿠폰 / 박스 인쇄 / Supabase serial_codes 장부 / 입력폼·API 정규식 4곳이 글자 단위로 동일해야 동작.
  • 등급 2(회복러)부터 코드 발급 → 등급이 오를수록 커미션율 상향으로 활동 유지.

현황 진단 (brain.db + 카페24 데이터 기반)
  • 1점 리뷰 6건 전부 미답변 즉시 조치
    3/25 기준 — 관리자 댓글 0건. 잠재 고객이 그대로 이탈 중.
  • WS-200 부정 리뷰 비율 13.3% 위험
    제품별 이슈가 CS 대응 전략에 반영되어 있지 않음.
  • 부정 리뷰 대부분 "불만족" "별로에요" — 이유 불명 주의
    고객 소통 채널(Q&A) 부재. 불만 원인 파악 불가 → 개선 불가능한 구조.
  • 리뷰 #500·#499 — 주문번호만 적은 CS 문의 의도 연락 필요
    리뷰를 CS 채널로 사용하는 고객 존재. 별도 응대 경로 없음.
  • 자동 배송 안내 문자 운영 중 (ES-808 D+14) 진행 중
    CRM 자동문자 시스템 구축됨. 이를 CS 여정에 통합 확장 가능.

02 고객 여정 매핑

주력 제품 ES-808 기준. 구매 → 배송 → 사용 → 재구매/크로스셀 전체 여정.

STAGE 1
🛒 구매 결정
· 광고 클릭 (메타/유튜브)
· 상세페이지 열람
· 리뷰 확인 (150개+)
✨ 리뷰 신뢰도가 전환 결정
⚠️ 1점 미답변 → 이탈
STAGE 2
📦 배송 대기
· 주문 확인 문자 (자동)
· 배송 조회 안내
· 대기 불안 발생
✨ 선제적 배송 안내
⚠️ 배송 지연 문의 폭증
STAGE 3
📬 수령 직후
· 언박싱 경험
· 사용 가이드 확인
· D+1 환영 문자
✨ 첫 사용 성공 = 장기 팬
⚠️ "어떻게 써요?" 최다
STAGE 4
💪 사용 기간
· 1~2주 효과 체감
· D+7 효과 확인 문자
· D+14 크로스셀 CRM
✨ 효과 체감 → 리뷰 유도
⚠️ 불만족 → 부정 리뷰
STAGE 5
⭐ 리뷰/추천
· D+21 리뷰 요청 문자
· 포토 리뷰 인센티브
· 지인 추천 유도
✨ 리뷰 = 다음 고객 전환
⚠️ 유도 없으면 침묵
STAGE 6
🔄 재구매/크로스셀
· ES-808 → CS-25
· +CS-25 → WS-200
· 정기 케어 프로그램
✨ 루틴 완성 = 브랜드 팬
⚠️ 타이밍 놓치면 이탈
📌 크로스셀 원칙: ES-808만 → CS-25 우선 / ES-808+CS-25 → WS-200 / 3개 보유 → 케어 프로그램

08 CS 답변 품질 가이드
📋 외주 CS 담당자가 바로 사용할 수 있는 실무 가이드. 스크립트가 아닌 기준이다 — 상황에 맞게 적용하되 틀을 지킬 것.
🎙️ 톤 & 매너 기준
✅ 해야 할 것
존댓말 항상 존댓말. "해요/습니다" 혼용 가능하되 일관성 유지

공감 먼저 문제 설명 전에 감정 공감 먼저. "불편드려서 정말 죄송합니다"

해결책 제시 원인 + 구체적 해결방법. "~해드리겠습니다" 명확히

감사 마무리 모든 답변 끝에 감사 표현. "소중한 말씀 감사합니다"

✔️ 필수 포함 요소 체크리스트
#요소예시필수
①인사"안녕하세요, 테넥스/키네메디칼 CS입니다 😊"필수
②공감 표현"불편드려서 정말 죄송합니다" / "많이 당황하셨겠어요"필수
③원인 + 해결책"확인해보니 ~의 문제로 보입니다. ~로 해결해드리겠습니다"필수

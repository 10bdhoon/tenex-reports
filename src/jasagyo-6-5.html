📋 핵심 요약
메타 광고 캠페인은 전환수 극대화 / 전환값 극대화 / 페이지 조회 3개만 사용한다. 캠페인을 분리하는 기준은 오직 '전환 목표'뿐이며, 제품별·테스트별 분리는 금지. 세트 생성의 조건은 가격대. 타겟 중복은 경매 기회를 잡아먹기 때문에 구조적으로 최소화해야 하고, 전환수·전환값·페이지 조회 3개는 타겟 중복률이 거의 없다는 것이 핵심 인사이트. 파트너 광고는 한국에서 활용하는 사람이 거의 없어 경매에서 유리하므로 적극 활용 권장.

되는 놈만 계속 내리는 슬로우 모션 (메타의 멀티 알고리즘)
🎯 액션 아이템
  • 캠페인 3개(전환수/전환값/페이지) 외 불필요한 캠페인 정리
  • 타겟 중복률 체크 — 메타 광고 관리자에서 타겟 중복 확인
  • 파트너 광고(Partnership Ads) 세팅 검토
  • 세트 분리 기준을 가격대로만 운영하도록 정리
💡 주요 개념 & 인사이트
  • 판매 캠페인은 풀퍼널 커버 — 잠재고객부터 구매 의향 높은 사람까지 모두 포함 (상세 페이지 조회 목표로 위쪽 퍼널도 가능)
  • 캠페인 분리 기준 = 전환 목표만. 제품 다르다고 캠페인 분리하면 안 됨
  • 세트 분리 기준 = 가격대. 타겟 분리는 더 이상 의미 없음 (AI가 전연령 다 들어가서 필터링)
  • 타겟 중복 발생 시 ①셀프 CP 올림(자기 돈으로 자기끼리 경쟁) ②입찰 기회 손실(100번 가능한데 97번만) ③성과 기여 왜곡
  • A캠페인이 노출하고 B캠페인이 전환 가져가는 기여 왜곡 현상 — 두 캠페인 간 진짜 성과 비교 불가능
  • 싼 제품(3만원)과 비싼 제품(5만원) 같이 넣으면 전환수 극대화에서 싼 제품만 타게 되어 비싼 제품 데이터 쌓임 기회 없어짐
  • 파트너 광고: 국내 활용자 거의 없어 경매에서 유리. 주기성 있게 활용 시 ROAS 두 배 효과 사례
  • 과거 AI 약할 때는 타겟 사전 정의 필요했지만, 현재는 메타 AI가 전 연령 다 넣고 내부에서 최적 필터링
  • 메타가 권장하는 방향 = 판매 캠페인 중심, 전환 목표 기반 구조
  • 퍼시(Persy) 브랜드와 파트너 광고 실험에서 좋은 결과 도출한 사례 언급
🔧 실무 적용 포인트
  • 캠페인 개수 = 최대 3개 (전환수 극대화 판매 / 전환값 극대화 / 페이지 조회)
  • 제품 여러 개일 때 → 같은 캠페인 안에서 세트만 분리 (가격대 기준)
  • 타겟 중복 확인: 구글에서 '메타 타겟 중복' 검색하면 공식 문서 나옴
  • 비싼 제품 지키려면 → 별도 캠페인에 최저 예산 부여해서 데이터 보호
  • A캠페인 끄고 B 켰는데 성과 나왔다 → 사실 A가 누적해준 데이터 덕분일 가능성 높음 (착시 주의)
  • 캠페인은 동반자 — 장기적으로 함께 가는 구조로 설계

⚡ 이벤트 기반 구조 & 비용

상시 가동 vs 이벤트 기반

❌ 상시 가동 (비효율)

에이전트 20명이 24시간 대기
→ 안 쓸 때도 비용 발생
→ 컨텍스트 폭발
→ 리셋/다운 빈번

✅ 이벤트 기반 (효율)

이벤트 발생 시에만 깨어남
→ 작업 완료 후 소멸
→ 비용 = 실제 사용량만
→ 안정적 (컨텍스트 안 쌓임)

2인 1조 구조 (실행 + 검증)

혼자면 자기 실수를 자기가 못 찾음. 최소 2명이 서로 검증.

리뷰어 → "타겟 맞아? 카피 약해" 피드백
→ 수정 → 완료

⏱️ 타임아웃 방어

작업 분할 + 체크포인트. 중간 저장 후 이어서 작업. 큰 작업은 자동 분할.

🔄 리셋 방어

상태를 파일(TASK.md, STATUS.md)로 관리. 세션 리셋돼도 파일 읽고 이어서.

📦 컨텍스트 관리

MEMORY.md 20,000자 이하 유지. brain.db로 아카이브. PDF는 서브에이전트 처리.

💡 에이전트 간 협업 패턴

에이전트는 상시 대기 않고 이벤트 발생 시에만 소환됨. 혼자 일하면 자기 실수를 못 잡으니 2인 1조 구조 — 실행 에이전트가 만들고, 리뷰어 에이전트가 검증.

  • 📣 마케팅팀: 크리에이터 → 소재 생성 / 리뷰어 → "타겟 맞아? 카피 약해" 피드백 → 수정
  • 🔧 개발팀: 개발자 → 코드 작성 / 리뷰어 → 리뷰 + 테스트 → 배포 승인
  • 📊 데이터팀: 분석가 → 수집/분석 / 검증자 → 수치 확인 + 인사이트 보충

협업 패턴: 크론잡 → 데이터봇 → 분석 완료 → 카리나 → 태훈 보고. 팀장이 task에 따라 필요한 전문가만 spawn → 작업 → 소멸.

💡 Phase 1 핵심 개념 — 보안 & 안정성

보안 하드닝이 왜 Phase 1인가: 와일드카드(*) 권한은 에이전트가 아무 명령이나 실행 가능한 상태. Gateway는 TLS 암호화 + bind 127.0.0.1 + 토큰 인증으로 잠가야 하고, exec allowlist를 node/curl/git만으로 제한해야 함. 이걸 안 하면 나중에 에이전트팀이 커질수록 리스크가 기하급수적으로 커짐.

안정성 3원칙: ① 상태를 파일(TASK.md)로 관리 — 세션 리셋돼도 파일 읽고 이어서 ② MEMORY.md 20,000자 이하 유지 (brain.db로 아카이브) ③ 큰 작업은 자동 분할 + 체크포인트

작업 분할 + 체크포인트. 중간 저장 후 이어서 작업. 큰 작업은 자동 분할.

🔄 리셋 방어

상태를 파일(TASK.md, STATUS.md)로 관리. 세션 리셋돼도 파일 읽고 이어서.

📦 컨텍스트 관리

MEMORY.md 20,000자 이하 유지. brain.db로 아카이브. PDF는 서브에이전트 처리.

🚫 폭주 방지

에이전트별 일일 실행 횟수 제한. 비용 상한선 설정. 무한 루프 감지.

👁️ 모니터링

HEARTBEAT.md로 에이전트 상태 추적. 장애 시 즉시 슬랙/텔레그램 알림.

🔒 보안

와일드카드 권한 제거. groupPolicy 제한. exec allowlist (node/curl/git만).

💡 트러블슈팅 — 문제 생기면 이렇게
  • 🛑 에이전트 멈출 때: log 확인 → 타임아웃/에러/무한루프 판단 → 재실행
  • 🤔 응답 이상할 때: SOUL.md 확인, 컨텍스트 오염 여부, 모델 선택, 프롬프트 수정
  • 💸 비용 폭발할 때: session_status 확인, 하트비트 간격↑, 모델 다운그레이드, 불필요 크론잡 OFF

왜 이게 핵심인가

  • ✅ 광고비 0원 — 성과 없으면 비용 없음
  • ✅ 타인증명 — "전문가가 추천"하는 구조
  • ✅ 자발적 바이럴 — 인플루언서가 알아서 홍보
  • ✅ 스케일 무제한 — 인플루언서 수 = 영업팀 규모
  • ✅ 데이터 추적 — 코드별 매출/전환율 측정

테넥스 적용 계획

  • 🎯 1차 타겟: 도수치료사 유튜버/인스타그래머
  • 🎯 2차 타겟: 운동/재활/헬스 크리에이터
  • 🎯 3차 타겟: 일반 건강/라이프 인플루언서
  • 🔧 시스템: 카페24 쿠폰 + 추적 대시보드
  • 🤖 자동화: 발굴 → 제안 → 코드 발급 → 정산

💡 키네메디칼 3중 타인증명 구조: 1분도수(전문가) + 정선근 교수(권위) + 인플루언서 추천코드(대중) = 신뢰 완전체

API vs MCP vs 스킬

  • API — 직접 호출, 코드 필요, 자유도 높음
  • MCP — 통역사. 에이전트가 도구처럼 직접 호출, 코드 불필요
  • 스킬 — 번들(내장) / ClawHub(마켓) / 커스텀(직접 제작)

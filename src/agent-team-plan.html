왜 이게 핵심인가

  • ✅ 광고비 0원 — 성과 없으면 비용 없음
  • ✅ 타인증명 — "전문가가 추천"하는 구조
  • ✅ 자발적 바이럴 — 인플루언서가 알아서 홍보
  • ✅ 스케일 무제한 — 인플루언서 수 = 영업팀 규모
  • ✅ 데이터 추적 — 코드별 매출/전환율 측정

테넥스 적용 계획

  • 🎯 1차 타겟: 도수치료사 유튜버/인스타그래머
  • 🎯 2차 타겟: 운동/재활/헬스 크리에이터
  • 🎯 3차 타겟: 일반 건강/라이프 인플루언서
  • 🔧 시스템: 카페24 쿠폰 + 추적 대시보드
  • 🤖 자동화: 인플루언서 발굴 → 제안 → 코드 발급 → 정산

💡 키네메디칼 3중 타인증명 구조와 시너지: 1분도수(전문가) + 정선근 교수(권위) + 인플루언서 추천코드(대중) = 신뢰 완전체

⚡ 이벤트 기반 구조 & 비용

상시 가동 vs 이벤트 기반

❌ 상시 가동 (비효율)

에이전트 20명이 24시간 대기
→ 안 쓸 때도 비용 발생
→ 컨텍스트 폭발
→ 리셋/다운 빈번

✅ 이벤트 기반 (효율)

이벤트 발생 시에만 깨어남
→ 작업 완료 후 소멸
→ 비용 = 실제 사용량만
→ 안정적 (컨텍스트 안 쌓임)

2인 1조 구조 (실행 + 검증)

혼자면 자기 실수를 자기가 못 찾음. 최소 2명이 서로 검증.

📣 마케팅팀

크리에이터 → 소재 생성
리뷰어 → "타겟 맞아? 카피 약해" 피드백
→ 수정 → 완료

🔧 개발팀

개발자 → 코드 작성
리뷰어 → 코드 리뷰 + 테스트
→ 수정 → 배포 승인

📊 데이터팀

분석가 → 데이터 수집/분석
검증자 → 수치 검증 + 인사이트 보충
→ 리포트 완성

💬 CS팀

응대원 → 1차 자동 응대
매니저 → 환불/에스컬레이션 판단
→ 필요 시 태훈 알림

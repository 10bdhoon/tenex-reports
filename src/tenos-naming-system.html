TENOS 네이밍 체계 & 코어 모듈

TENOS는 단순 엔진 이름이 아니라, Tenex Operating System이라는 운영체계 이름이다. 즉 OpenClaw 대체용 런타임만이 아니라, 테넥스 AI 조직 전체를 굴리는 공용 언어이자 시스템 이름으로 쓰인다.

정식명: TENOS
확장명: Tenex Operating System
포지션: 테넥스 AI 조직 운영체계
용도: OpenClaw 대체 런타임 + 메모리 + 라우팅 언어

1. 이름 정의

확정
TENOS
Tenex Operating System

테넥스의 AI 조직, 기억, 라우팅, 승인, 자동화를 하나의 운영체계처럼 묶는 이름.

한 줄 정의

테넥스 AI 조직을 굴리는 자체 운영체계

카리나, 실장, 팀원, brain.db, 보고 루프, 자동화를 하나의 런타임 구조로 묶는 시스템.

3. 코어 모듈 책임범위

모듈역할무엇을 책임지나
TENOS Router입력 관문사용자 메시지, 슬랙 멘션, 웹훅, 크론 이벤트를 받아 표준 task envelope로 변환
TENOS Runtime실행 허브카리나/실장 세션 유지, 팀원 spawn, timeout, retry, fallback 관리
TENOS Memory기억 주입기brain.db 검색, MEMORY/HEARTBEAT 주입, 작업 후 결과 저장
TENOS Flow업무 오케스트레이션카리나 처리 / 실장 위임 / 팀원 호출 / 보고 경로 분기
TENOS Core정책 레이어권한, 승인, 위험 작업 제한, 사람 승인 조건, 조직 원칙 유지
TENOS Console관리 인터페이스시스템 상태, 작업 상태, 승인지점, 로그, 메모리 상태 시각화

4. 실제 흐름에서 어떻게 쓰이나

Step 1
TENOS Router
태훈의 텔레그램 메시지, 슬랙 지시, 자동 이벤트를 수신한다.
  • 누가 보냈는지
  • 어디서 왔는지
  • 무슨 종류인지
Step 2
TENOS Flow
카리나 직접 처리인지, 실장 위임인지, 팀원 spawn이 필요한지 결정한다.
  • 분배
  • 오케스트레이션
  • 보고 경로 결정
Step 3
TENOS Memory
작업 전 관련 기억을 붙이고, 진행 상태를 추적하고, 끝나면 저장한다.
  • brain.db 검색
  • HEARTBEAT 반영
  • 결과 저장
Step 4
TENOS Runtime
카리나/실장 세션을 유지하고, 필요시 worker를 띄워 실행하고 종료한다.
  • lead 유지
  • worker spawn
  • retry/fallback

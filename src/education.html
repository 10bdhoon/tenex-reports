📚 자사교 5기 | 메타 광고 교육

자사교 5기 메타 광고 강의 핵심 정리

강의자: 김성현 대표 | 1~5주차 12개 강의 전사본 요약

1~5주차 강의 12개 태훈 조교 참여
← 테넥스 리포트 홈
1

1주차 — 메타 광고 철학 + 비즈니스 포트폴리오 온보딩

강의 01, 02 | 메타의 작동 원리, 픽셀/전환 API, 계정 구조 설정

🎯 주요 주제

  • 메타가 AI에 투자하는 이유 (광고 수익 90%+)
  • 비즈니스 포트폴리오 구조 이해
  • 픽셀 vs 전환 API (CAPI) 작동 원리
  • 데이터 시그널의 중요성
  • 메타 비즈니스 스위트 vs 포트폴리오 차이

💡 핵심 개념/프레임워크

  • 전환 API (경리 비유): 쿠키리스 시대에 픽셀 한계 극복, 직접 서버→메타 데이터 전송
  • 행동 지문 타겟팅: 집단 그룹이 아닌 개인 행동 패턴 기반
  • 계정 권한 구조: 대표(전체관리) → 직원(부분관리) → 대행사(파트너)
  • 재구매 루프: 첫구매→CRM→재구매→높은 LTV

📊 주요 수치/데이터

  • 메타 광고 수익 비중: 97%
  • 강사 스킨스쿨 ROAS: 광고비 26억 → 매출 207억 (자사몰)
  • 재구매 비율: 82% (스킨스쿨 기준)
  • 메타 AI 개발자 평균 연봉: 135억
  • 메타 2030 AI 투자 계획: 286조
  • 기여 윈도우: 클릭 7일, 조회 24시간

🔥 실행 가능한 핵심 인사이트

비즈니스 포트폴리오는 법인처럼 관리하라. 대표 2명만 전체관리 권한 부여 (직원/대행사에 전체관리 절대 금지). 한 개 법인 = 한 개 포트폴리오로 통합 운영해야 신뢰 점수가 쌓인다. 전환 API 설정은 필수 — 쿠키리스 환경에서 픽셀만으론 부족하다. 메타는 클릭→구매 매칭에서 거의 100% 정확도를 보이므로 데이터 신뢰 가능.

🏥 키네메디칼/테넥스 적용 포인트

  • CS-25, ES-808 각 제품별 광고 계정 분리 (비즈니스 포트폴리오는 법인 1개로 통합)
  • 전환 API 설정 완료 여부 점검 — 카페24 픽셀 + CAPI 양방향 확인
  • CRM 자동화(현재 ES-808 배송 문자)를 재구매 고객 분류까지 확장
  • 태훈이 조교로 참여했으므로 강의 세팅 방법론 직접 숙지 가능
2

2주차 — 메타 경매 시스템 + 마케팅팀 설정

강의 03, 04 | 경매 4단계, 총가치 공식, 입찰 전략, 타겟 세그먼트

🎯 주요 주제

  • 메타 경매 4단계 작동 원리
  • 총가치(Total Value) 공식
  • 입찰 전략: 지출기반 vs 목표기반
  • 타겟 세그먼트(참여/기존 고객) 설정
  • 믹스패널 연동 및 UTM 설정

💡 핵심 개념/프레임워크

  • 경매 공식: 광고비 × 추산행동률 + 광고품질 + 자사몰 점수
  • 4단계: 필터링→리트리벌→시퀀스러닝→라이트스(최종경매)
  • 스노볼 효과: 좋은 데이터 쌓이면 총가치↑ → 더 많은 노출 → 더 많은 데이터
  • 멀티암 밴디 알고리즘: 모든 광고에 최소 기회 보장, 잘 되는 광고에 더 많은 기회

📊 주요 수치/데이터

  • 필터링: 빈도/정책/노출 위치 검수 (노출 위치 자동화 필수)
  • 리트리벌: 광고 관련성 계산 (릴스형 소재에 베타 베네핏↑)
  • 목표기반 입찰: 예산 소진 안 함 (로아스 안 나오면 자동 중단)
  • 클래스101 광고 계정: 월 7억 집행 사례

🔥 실행 가능한 핵심 인사이트

메타와 싸우지 말고 올라타라. 경매를 이기려는 꼼수 대신 총가치를 높이는 데 집중. 노출 위치 제한 금지(자동화), 릴스형 소재 우선, 광고 데이터 축적 후 성과 개선이 핵심 전략. 광고 끄기/켜기를 반복하면 스노볼이 깨진다 — 대신 좋은 소재 투입으로 방향 전환. 경매는 카테고리 무관 전국 모든 광고와 경쟁한다.

🏥 키네메디칼/테넥스 적용 포인트

  • CS-25(2만원대)와 ES-808(고가)는 가격대가 달라 광고 세트 분리 필수
  • 릴스형 소재 제작 우선순위 상향 — 목/허리 운동 영상 릴스 최적화
  • 광고 성과 부진 시 캠페인 OFF 대신 새 소재 투입으로 대응
  • 믹스패널 연동으로 광고→상세페이지→구매 퍼널 전체 분석 가능하게 유지
  • 타겟 세그먼트: 참여(상세 방문 미구매) / 기존 고객(구매자) 분리 설정
3

3주차 — 광고 관리자 실습 + 크리에이티브 전략

강의 05, 06, 07, 08 | 캠페인 셋업, 크리에이티브 테스트, 콘텐츠 벤치마킹

🎯 주요 주제

  • 광고 관리자 A~Z 실습 (캠페인→세트→광고)
  • 어드벤티지플러스 통합 기능 활용
  • 크리에이티브 테스트 (신규 기능)
  • 파트너십 광고 장단점
  • 콘텐츠 벤치마킹 방법론
  • 광고 세트 분리 기준

💡 핵심 개념/프레임워크

  • 크리에이티브 테스트: 세트/캠페인 추가 없이 기존 세트 내에서 2주 균등 예산 테스트 → 머신러닝 영향 0
  • 세트 분리 2가지 기준만: ①거시적 타겟이 완전히 다를 때 ②가격대가 크게 다를 때
  • 광고 수명: 수명 없음. 빈도(경쟁사 등장)가 수명 결정
  • 셀프 벤치마킹: 훅률/지속율/CTR 조합 분석 → 더 강한 버전 제작

📊 주요 수치/데이터

  • 좋은 소재 훅률: 40%+, 지속율: 15%+, CTR: 3%+
  • 릴스 노출 비중: 60~70%
  • 세트 내 광고 5개가 균등 예산 분배되는 게 이상적
  • 1초 편집 차이로 성과 1.5배 차이 사례
  • 이미지 광고 1개 혼합: 피드 지면 로아스 최고

🔥 실행 가능한 핵심 인사이트

50개 던지기보다 5개 뾰족하게. 크리에이티브 테스트로 현재 1등 소재보다 더 강한 소재를 단계적으로 제작. 내 광고 데이터(훅률·지속율·CTR)를 분석해 가장 약한 지점을 개선한 버전 제작 → 투입 → 승자 독식 확인 → 반복. 어드벤티지플러스 통합 기능은 무조건 켜둬야 함 (리타겟도 마찬가지). 광고 관리자 하루 2000번 들어가는 습관은 금물 — 7일은 절대 건드리지 말 것.

🏥 키네메디칼/테넥스 적용 포인트

  • ES-808: 목 디스크 통증 문제→해결 구조 릴스 소재 3~5개 집중 테스트
  • CS-25: 가격 경쟁력 + 치료사 신뢰도 소재 조합 테스트
  • 1분도수 채널 콘텐츠를 파트너십 광고 소재로 활용 검토 (팔로워 타겟 매칭)
  • 이미지 광고 1개(할인 소구) + 릴스 4개 조합이 이상적 세트 구성
  • 크리에이티브 테스트: 기존 캠페인 내에서 새 소재 실험 → 학습 보존
4

4주차 — 머신러닝 이해 + 성과 분석

강의 09, 10 | 머신러닝 원리, 퍼널 분석, 믹스패널 대시보드, CRM 연계

🎯 주요 주제

  • 머신러닝 작동 원리 (후보 선별→확률 예측→노출)
  • 증분 기여(증대 기어) vs 일반 기어
  • 광고 퍼널: 광고 반응 + 자사몰 퍼널 분석
  • 믹스패널 대시보드로 이탈 지점 파악
  • 히트맵/세션 리플레이로 상세 페이지 UX 개선
  • VOC → CRM 자동화 설계

💡 핵심 개념/프레임워크

  • 곱셈 법칙: 광고 성과 = CTR × 체류 × 결제시작 × 구매 (각 10% 개선 → 복리 효과)
  • 증분 기여: 메타를 통해서만 산 사람 분리 측정 → 실제 광고 기여도 확인
  • 50개 신화 해체: 머신러닝은 20개도 됨, AI 발전으로 훨씬 빨라짐
  • 광고 계정 분리 위험: 계정 여러 개면 1구매→3구매 중복 측정 발생

📊 주요 수치/데이터

  • 머신러닝 시작: 과거 50개→현재 20개도 가능
  • 2회 재구매 시 이후 재구매율 급등 (스킨스쿨 데이터)
  • 디자이너 1년 AB테스트로 전환율 1%도 못 올리면 해고 기준
  • 브랜드 여러 개: 포트폴리오 1개 공유, 광고 계정은 각각 분리

🔥 실행 가능한 핵심 인사이트

문제는 광고가 아니라 퍼널에 있다. 로아스가 나쁘면 광고 소재만 바꾸지 말고 믹스패널로 이탈 지점을 먼저 찾아라. 상세 페이지가 문제면 광고 바꿔도 소용없다. 증분 기여 분석으로 "실제 메타 때문에 산" 사람과 "원래 살 사람"을 구분해 광고비 효율성을 정확히 측정. VOC(고객 전화)는 정량 데이터의 원인을 찾는 핵심 도구 — 매달 10명 이상 전화 필수.

🏥 키네메디칼/테넥스 적용 포인트

  • ES-808 구매자 전화 VOC: "어떤 광고 보고 샀냐", "상세 페이지 어디서 막혔냐" 파악
  • 믹스패널 퍼널: 상세 입장→사용법 클릭→장바구니→구매 단계별 이탈율 분석
  • CS-25 낮은 가격 → 높은 구매 확률 → 먼저 머신러닝 달성 가능성 높음
  • ES-808 고가 제품: 2회 구매 고객에게 적극 CRM → 충성고객 전환 집중
  • 키네메디칼 법인 1개 포트폴리오 유지하되 CS-25/ES-808 광고 계정 분리 확인
5

5주차 — AS플러스 카탈로그 + 계정 보안 + 최종 셋업

강의 11, 12 | 카탈로그 최적화, 제품 속성 설정, 쇼스, 보안 관리

🎯 주요 주제

  • AS플러스 카탈로그 vs 일반 광고 차이
  • 카탈로그 속성 필드 우선순위 설정
  • 제품명/설명 작성 룰 (메타 가이드)
  • 비디오 카탈로그 등록 방법
  • 쇼스(Shops) 기능 활용
  • 2단계 인증 + 해킹 방어 + 2주의 법칙

💡 핵심 개념/프레임워크

  • 카탈로그 = 황금알 거위: 제품 정보 잘 입력하면 장기적으로 최고 효율
  • 속성 필드: 도서 분류 코드 (없으면 검색 안 됨)
  • 제품명 룰: 특징+제품명+용량/수량 or 제품명+색상+사이즈
  • 2주의 법칙: 신규 계정/신규 광고는 2주간 안전한 광고로 신뢰 쌓기
  • 카탈로그 셋업: 신규+리타겟 5:5, 가치 최적화

📊 주요 수치/데이터

  • 제품 설명 최대 9,999자 (하지만 핵심 500자 이내 권장)
  • 엔젤비 사례: 1년된 소재가 아직도 1등 (수명 없음 증명)
  • 해킹 환불 조건: 2단계 인증 "모두" 설정 필수
  • 비디오 카탈로그: 메타가 가장 강하게 미는 기능 (2025 기준)
  • 카탈로그 이 설정 하는 업체: 대한민국 0.01% 미만

🔥 실행 가능한 핵심 인사이트

카탈로그 속성 잘 채우면 상대 경쟁 우위 확보. 대한민국에서 이걸 제대로 하는 업체가 거의 없기 때문에, 제품 속성(성별·연령·색상·소재·특징)을 정확히 입력하는 것만으로 경매에서 관련성 점수 우위를 가져갈 수 있다. 비디오 카탈로그가 메타의 현재 미래 방향 — 릴스 소재를 카탈로그에 연결하면 자동 최적화. 보안은 선택이 아닌 필수: 2단계 인증 "모두" 설정 + 메타 발신 메일 무조건 무시.

🏥 키네메디칼/테넥스 적용 포인트

  • ES-808/CS-25 카탈로그 속성: 부위(목/허리), 강도, 적용 대상(연령), 소재 등 세밀하게 입력
  • 제품명 룰 적용: "목디스크 완화 ES-808 목 근막 이완기 2025형" 형식으로
  • 1분도수 유튜브 영상 → 비디오 카탈로그 연결 검토 (콘텐츠 자산 활용)
  • 비즈니스 포트폴리오 2단계 인증 "모두"로 즉시 설정 확인 필수
  • 카탈로그: 신규 고객 5 / 리타겟 고객 5 비율, 가치 최적화 캠페인 운영

📐 메타 광고의 핵심 철학

  • 메타의 미래: AI가 알아서 광고 제작+최적화

🚫 하지 말아야 할 것들

  • 캠페인 여러 개 동시 운영 (성과 분산)

🏆 핵심 공식: 메타 광고 성과 = 총가치 × 지속성

총가치 = 광고비(입찰가) × 추산행동률 + 광고품질(관련성) + 자사몰 점수(랜딩페이지 UX)

자사몰 운영의 꽃은 재구매 — 메타는 신규 고객 유입 도구, CRM은 재구매 도구. 두 개를 결합해야 진정한 자사몰 성과를 만들 수 있다. 광고 소재 1개가 수개월 이상 1등을 유지할 수 있다 (빈도/경쟁사가 수명을 결정하지 시간이 아님).

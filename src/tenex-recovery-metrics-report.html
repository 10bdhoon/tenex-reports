01

왜 「숫자」가 해자인가

The InBody Playbook

질문에 먼저 답한다. 인바디는 처음부터 의료기기가 맞다. 1996년 차기철 박사가 창업, 체성분분석기(BIA)는 출시 시점부터 의료기기로 등록됐다. 하지만 인바디의 진짜 무기는 「의료기기 타이틀」이 아니라 그것을 쓴 전략이었다.

이 플레이북이 우리 그림과 정확히 겹친다

지성 대표가 그리는 「굿플 의료기기 로고 → 메디스트림·물작메 침투 → 전문가 인증 → 더현대 팝업 → 단계별 확산」은 인바디의 "병원 선점 후 대중 확산"과 동일한 구조다. 한 가지가 빠져 있을 뿐이다 — 우리만의 숫자.

핵심 명제. 인바디가 「체성분」을 독점했듯, 우리는 「근골격 회복도」를 숫자로 정의하는 최초 브랜드가 된다. 정의하는 자가 표준이 되고, 표준은 데이터로 굳는다.

숫자가 만드는 4가지 자산

자산설명
① 신뢰"좋아졌다"는 주관적 후기 → "목 회전 18° 개선" 객관 수치. 의료계가 받아들이는 언어.
② 재구매 트리거점수가 떨어지면 운동·제품 사용의 동기가 생긴다. 측정이 루프의 시동 키.
③ 광고 무기"N천 명 평균 ROM 18° 개선" 같은 임상급 클레임 → 전환율·CPA 개선.
④ 진입장벽before/after 데이터는 복리로 쌓인다. 후발주자가 시간으로도 못 따라잡는 해자.

ES-808 측정지표

Pain & Recovery Numbers
ES-808
ES-808 · 저주파 회복기 — 「통증·회복의 숫자」
다관절(목·어깨·팔꿈치·손목·무릎·발목) — 얼마나 아팠고, 얼마나 풀렸는가

ES-808은 회복기기다. CVA 같은 자세 각도가 아니라, 통증의 크기·관절별 가동성·근육 상태를 숫자로 잡아야 한다. 다관절 기기이므로 「부위별」로 쪼개는 것이 핵심이다.

지표정의 / 척도측정 방법난이도임팩트
통증 강도 (NRS/VAS)0~10 숫자 통증척도. 부위별 개별 기록앱 자가입력(매 세션)하★★★

트리거포인트 수활성 압통점 개수 변화자가 체크 + 부위 매핑하★
ES-808의 차별화 한 방 = 근긴장도 센서. 통증·ROM은 경쟁사도 앱으로 흉내 낼 수 있다. 하지만 7월 말 굿플 의료기기 버전에 근경도/EMG 센서를 내장하면 — "의료기기로 측정한 근육 이완 수치"가 된다. 앱이 못 넘는 하드웨어 해자이자, 의료계 신뢰의 결정타.

난이도 ↔ 시점의 분리

난이도 「하」(통증·통증지도·회복속도)는 지금 당장 앱만으로 시작한다. 「상」(PPT·근긴장도)은 굿플 의료기기 버전에 얹어 신뢰 레이어로 올린다. 모든 걸 한 번에 하지 않고 단계로 쌓는다.

통합지수 「KINE Score」

One Number to Remember

사람은 숫자 하나로 기억한다. 인바디가 「InBody Score」로 모든 지표를 묶었듯, 우리는 두 제품 라인을 하나의 KINE Index (0~100)로 통합한다.

P-Score
POSTURE · CS-25 라인
CVA + 경추ROM + 정렬
R-Score
RECOVERY · ES-808 라인
통증 + 관절ROM + 근이완
KINE
통합 INDEX
두 점수의 가중 종합

MVP 산식 (시작 버전)

POSTURE Score = CVA 정규화(50%) + 경추 ROM 6방향 평균(35%) + 어깨 정렬(15%)

RECOVERY Score = (10 − NRS)×40% + 관절 ROM 회복률(40%) + 순응도(20%)

KINE Index = POSTURE × 0.5 + RECOVERY × 0.5  (제품 보유에 따라 가중치 자동 조정)

측정 항목이 적은 초기엔 보유 지표만으로 산출하고 데이터가 쌓이면 가중치를 보정한다(인바디도 모델마다 항목이 다르다). 중요한 건 "완벽한 산식"이 아니라 사용자가 매번 보는 점수가 하나 존재한다는 것이다.

점수의 시각화 = 재방문 동력

실행 로드맵 · BM 연결 · 다음 액션

Execution

측정수단 3단계 로드맵

PHASE 1
지금~
앱 + 폰카메라 (장비 0) — CVA·거북목, 관절 ROM(AI 포즈추정), 통증일지·통증지도. 진입장벽 없이 즉시 "우리 숫자" 가동. → 데이터 수집 시작이 최우선
PHASE 2
7월말
굿플 의료기기 + 센서 — 근긴장도·근경도, 압통역치(PPT)를 의료기기 버전에 내장. "의료기기로 측정한 수치" = 신뢰 레이어 + 하드웨어 해자.
PHASE 3
데이터後
임상화 — N천 명 before/after 축적 → "키네 사용 시 경추 ROM 평균 18° 개선" 임상급 클레임 → 논문·학회·광고·진입장벽으로 전환.

대표가 그린 루프(기기→소모품 반복→운동 영상→제품사용 마무리→재구매)에 측정이 시동과 검증을 모두 담당한다. 숫자가 없으면 루프는 "느낌"으로 끊긴다. 숫자가 있으면 "데이터로 효과가 보여서" 멈출 수 없다.

의료계 침투에서 숫자의 역할

단계숫자가 하는 일
메디스트림·물작메"환자 ROM·통증 추적 데이터를 제공하는 기기" → 전문가가 임상에 쓸 명분. 후기가 아니라 데이터로 말한다.
전문가 인증물리치료사·의사가 측정값으로 효과 검증 → 추천 근거 확보.
더현대 팝업즉석 CVA 측정 사진 → "당신 목 38°" 충격 → 현장 전환.

즉시 실행 (Next Actions)

1
Phase 1 MVP 측정 범위 확정 — CVA·경추ROM·관절ROM·통증일지 4종으로 앱 스펙 동결. (의사결정 필요)
2
KINE Score 산식 v0 승인 — 위 MVP 산식으로 시작, 데이터 후 보정 합의.
3
굿플 의료기기 버전 센서 사양 결정 — 근긴장도/PPT 센서 내장 여부·원가 영향 검토 (7월말 데드라인 역산).
4
측정 데이터 수집 설계 — before/after를 처음부터 구조화해 저장(Phase 3 임상화의 연료).
한 줄 결론. CS-25는 「구조(POSTURE)」, ES-808은 「회복(RECOVERY)」을 각각 숫자로 잡고, 둘을 KINE Score로 묶는다. 앱으로 지금 시작하고, 굿플 의료기기에 센서로 신뢰를 얹고, 데이터로 해자를 굳힌다. — 대표님, 어디부터 팔지(1번 MVP 범위 / 2번 산식 / 3번 센서 사양) 정해주시면 바로 깊게 들어갑니다.

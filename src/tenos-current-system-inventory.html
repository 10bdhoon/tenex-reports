TENOS As-Is System Inventory

TENOS로 옮기기 전에 먼저 해야 할 건, 지금 실제로 돌아가는 전체 시스템을 한 장에 적는 것이다. 이 페이지는 현재 테넥스 AI 운영체계의 인벤토리다. 즉 무엇이 존재하고, 누가 무엇을 하고, 어디에 기억이 쌓이고, 무엇이 자동으로 돈는지 먼저 명확히 적어두는 As-Is 시스템 지도다.

목적: 현행 시스템 빠짐없이 적기
다음 단계: 이 페이지 기준 Keep / Reference / Drop 분류
원칙: 모르는 상태로 옮기지 않는다

6. 현재 보고 / 승인 구조

핵심 운영 원칙: 태훈 → 카리나 → 실장 → 팀원 → 카리나 → 태훈 흐름이 기본이다. 고객대면, 광고 변경, 배포, 민감 작업은 사람 승인 또는 카리나 검수를 거친다.
보고

최종 보고 허브

카리나가 실장 결과를 받아 태훈에게 요약 보고하는 구조.

승인

민감 작업 게이트

광고 ON/OFF, 예산 변경, 운영/배포 위험작업은 승인 필요.

품질

초기 검수 우선

고객대면 콘텐츠나 CS는 사람 승인 비중이 큼.

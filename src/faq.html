🏷 제품 정보 8개
▶ ES-808 도수펜은 어떤 제품인가요? ES-808
ES-808 도수펜은 타겟형 저주파 마사지기입니다.

  • EMS (근육 자극) + TENS (통증 완화) 기능 내장
  • 아픈 부위를 콕 집어서 집중적으로 전기치료
  • 물리치료실에서 받는 전기치료를 집에서 가능
  • 호랑이 글루코사민 마사지 크림과 함께 사용하면 흡수 시너지 효과
입문용으로 추천! 129,000원으로 물리치료 10회분 가격에 반영구적 사용 가능
▶ CS-25 도수넥은 어떤 제품인가요? CS-25
CS-25 도수넥은 경추 견인 솔루션입니다. 9년 경력 도수치료사가 직접 설계했습니다.

  • 목뼈 C커브 복원 + 경추 정렬
  • 부드러운 견인으로 근육 긴장 완화
  • 하루 5~10분 누워서 사용
  • 목디스크, 거북목, 일자목, 버섯목 대상
고객 후기: "병원에서 견인기 하던 거보다 훨씬 좋아요", "10분만 하면 목이 사르르 편해져요"
메인 상품! 도수치료 2~3회 비용(약 40만원)으로 영구 사용 가능. 병원에서도 사용하는 제품입니다.
▶ WS-200 도수워머는 어떤 제품인가요? WS-200
WS-200 도수워머는 밀착형 근적외선 찜질기입니다. 국내 최초!

  • 108개 근적외선 LED 내장
  • 일반 찜질기와 달리 깊은 열 침투 (세포 재생 촉진)
  • 목 곡선에 밀착되는 설계
  • 가볍고 휴대 가능
일반 찜질기 vs WS-200: 일반 찜질기는 단순 표면 열 → WS-200은 근적외선으로 깊숙이 침투, 세포 재생 촉진
CS-25 사용 전 WS-200으로 근육을 먼저 풀어주면 효과가 배가됩니다!
▶ 호랑이 글루코사민 마사지 크림은 뭔가요? 크림
도수펜(ES-808)과 함께 사용하는 전용 마사지 크림입니다. (9,900원)

  • 크림을 바르고 도수펜으로 문지르면 흡수가 잘 됨
  • 글루코사민 성분으로 관절 케어 시너지
  • 평점 4.8/5.0 (12개 리뷰)
▶ 일반 마사지기랑 뭐가 다른가요? 비교
키네메디칼 제품은 도수치료 원리를 재현한 제품입니다. 일반 마사지기와는 근본적으로 다릅니다.

일반 안마기: 진동·두드림 → 그때만 시원, 근본 해결 X
키네메디칼: 견인·전기치료·근적외선 → 병원 물리치료 프로세스 재현

실제 고객 후기:
"시중에 나와있는 일반 목 마사지기랑은 확실히 차원이 다르고 퀄리티가 상당합니다."
"물리치료실에서 받는 거랑 완전 똑같더라고요"
▶ 병원에서도 사용하나요? 안전한가요? 신뢰
9년 경력 도수치료사가 직접 설계한 제품이며, 실제 병원에서도 사용되고 있습니다.

고객 후기: "병원에서도 쓰고 있는 제품이라던데 신뢰가 확 올라가요"

⚠️ 주의: 급성 염증, 임산부, 체내 금속 삽입물이 있는 경우 사용 전 전문의 상담을 권장합니다.
▶ 효과는 언제부터 느낄 수 있나요? 효과
개인차가 있지만 고객 후기 기준:

  • ES-808 도수펜: 첫 사용부터 "바로 가벼워짐을 느낌", "자극이 잘 오네요"
  • CS-25 도수넥: "10분만 하면 목이 사르르 편해져요" / 꾸준히 1달 사용 시 "통증이 기적처럼 사라짐"
  • WS-200 도수워머: "따뜻한 느낌이라 목이 가벼운 듯"
중증 환자(목디스크 등)의 경우: 처음 3일은 적응 기간이 필요할 수 있어요. WS-200 + ES-808으로 먼저 근육을 풀고 CS-25를 사용하면 효과가 훨씬 좋습니다.

  1. 통증이 있는 부위(트리거 포인트)를 찾아주세요
  2. 도수펜을 해당 부위에 밀착시켜주세요
  3. 강도를 낮은 단계부터 천천히 올려주세요
  4. 한 부위에 5~10분 사용 권장

추천 부위: 목 뒷부분, 어깨 결림 부위, 허리 통증 부위

▶ CS-25 도수넥은 어떻게 사용하나요? 사용법
  1. 평평한 바닥에 도수넥을 놓아주세요
  2. 그 위에 누워서 목을 올려놓아주세요
  3. 하루 5~10분 사용 권장
  4. 매일 꾸준히 사용하면 효과적

⚠️ 처음 사용 시: 중증 환자의 경우 처음 3일은 약간 불편할 수 있습니다. 이 경우 WS-200(도수워머)과 ES-808(도수펜)으로 먼저 근육을 풀어준 후 사용하세요.
고객 후기: "처음엔 아파서 못 썼는데, 도수워머+도수펜 먼저 하고 도수넥 했더니 완전 신세계였어요!"
▶ WS-200 도수워머는 어떻게 사용하나요? 사용법
  1. 목이나 어깨 등 통증 부위에 밀착시켜 감싸주세요
  2. 전원을 켜면 108개 근적외선 LED가 작동합니다
  3. 10~15분 사용 권장
  4. 사용 후 땀은 닦아서 보관해주세요

활용 부위: 목, 어깨, 허리 등 (연장선 사용 시 다양한 부위 가능)
CS-25(도수넥) 사용 전에 WS-200으로 먼저 근육을 풀어주면 효과가 배가됩니다. 물리치료실의 온열치료 원리와 동일해요!
▶ 처음 사용할 때 아픈데 정상인가요? 사용법
중증 환자(목디스크 등)의 경우 처음 2~3일은 약간 불편할 수 있습니다. 이는 정상적인 적응 과정입니다.

해결법:
  1. 먼저 WS-200(도수워머)로 찜질하여 근육 이완
  2. ES-808(도수펜)으로 전기치료
  3. 충분히 풀린 상태에서 CS-25(도수넥) 사용

실제 고객 후기: "처음 3일은 아파서 못 썼는데, CS 문의해서 조언 받고 도수워머+도수펜 먼저 하고 도수넥 했더니 완전 신세계였어요."
▶ 하루에 얼마나 사용해야 하나요? 사용법
  • ES-808 도수펜: 부위당 5~10분, 하루 1~2회
  • CS-25 도수넥: 하루 5~10분, 매일 사용 권장
  • WS-200 도수워머: 10~15분, 하루 1~2회

과하게 사용하기보다 매일 꾸준히 짧게 사용하는 것이 효과적입니다! 고객 후기: "1달 매일 하니까 통증이 기적처럼 사라졌네요."
▶ 가족이 같이 사용해도 되나요? 사용법
네! 온 가족이 돌아가면서 사용 가능합니다. 반영구적으로 사용 가능한 제품이에요.

고객 후기: "온 가족이 돌아가면서 사용해도 좋을 만큼 만족. 와이프도 써보고 '일반 사람도 시원하다고' 하네요. 저보다 더 오래 합니다 ㅋㅋ"
🔄 통합 사용 루틴 3개
▶ 3가지 제품을 함께 사용할 때 순서가 있나요? 루틴
물리치료실 프로세스를 그대로 재현하는 최적 순서:

Step 1. 🔥 도수워머 (WS-200) — 10~15분
→ 근적외선 찜질로 근육 이완 (온열치료)

Step 2. ⚡ 도수펜 (ES-808) — 5~10분
→ 전기치료로 통증 부위 집중 케어

Step 3. 🦴 도수넥 (CS-25) — 5~10분
→ 이완된 상태에서 경추 견인·교정

이 순서가 병원에서 물리치료받는 프로세스(온열 → 전기 → 견인)와 완전히 동일합니다! 고객 후기: "물리치료실에서 받는 거랑 완전 똑같더라고요"
▶ 하나만 사도 효과가 있나요? 루틴
네, 각 제품 단독으로도 충분히 효과적입니다!

  • ES-808만: 국소 통증 부위 전기치료 (입문용 추천)
  • CS-25만: 견인으로 경추 교정 (하루 5분이면 OK)
  • WS-200만: 찜질·온열치료 (근육 이완)

다만, 통합 사용 시 효과가 시너지를 이루기 때문에 중증 환자일수록 세트 사용을 추천드립니다.
추천 구매 순서: ES-808(입문) → CS-25(핵심) → WS-200(시너지 완성)
▶ 처음 구매한다면 어떤 제품부터 시작하면 좋나요? 추천
증상별 추천:

  • 국소 통증 (어깨, 허리 특정 부위) → ES-808 도수펜 (129,000원)
  • 목 통증 / 목디스크 / 거북목 → CS-25 도수넥 (398,000원)
  • 전반적 뻐근함 / 찜질 선호 → WS-200 도수워머 (128,000원)

가장 많이 선택하는 조합:
ES-808 + CS-25 (527,000원) — 전기치료 + 견인의 핵심 조합
📦 주문 / 배송 4개
▶ 배송은 얼마나 걸리나요? 배송
  • 결제 완료 후 1~3 영업일 이내 출고
  • 출고 후 1~2일 내 수령 (택배사 상황에 따라 상이)
  • 주말·공휴일은 출고 제외

배송 출발 시 운송장 번호가 안내되며, 카페24 마이페이지에서 배송 조회 가능합니다.
▶ 배송 조회는 어떻게 하나요? 배송
  1. 키네메디칼 자사몰 로그인
  2. 마이페이지 → 주문내역 확인
  3. 운송장 번호 클릭 시 택배사 추적 페이지로 이동

운송장이 아직 등록되지 않았다면 출고 준비 중입니다. 결제 후 1~3 영업일 이내 출고됩니다.
▶ 주문 취소/변경이 가능한가요? 주문
출고 전이라면 주문 취소 및 배송지 변경이 가능합니다.

  • 마이페이지에서 직접 취소 가능
  • 또는 1:1 문의로 주문번호와 함께 요청

⚠️ 출고 완료 후에는 취소가 불가하며, 수령 후 반품 절차를 이용해주세요.
▶ 배송비는 얼마인가요? 배송
자세한 배송비 정책은 키네메디칼 자사몰의 주문 페이지에서 확인 가능합니다.
도서산간 지역은 추가 배송비가 발생할 수 있습니다.
🔁 교환 / 반품 / AS 4개
▶ 교환/반품은 어떻게 하나요? 교환/반품
교환/반품 절차:
  1. 키네메디칼 자사몰 1:1 문의 또는 카카오채널로 접수
  2. 주문번호 + 사유를 알려주세요
  3. 접수 확인 후 안내 드립니다

  • 수령 후 7일 이내 신청 가능
  • 제품 하자 시 → 왕복 배송비 무료
  • 단순 변심 시 → 왕복 배송비 고객 부담
  • 사용 흔적이 있는 경우 교환/반품 불가할 수 있습니다
▶ 제품이 불량/고장인 것 같아요 불량
제품 불량이 의심되시면 즉시 1:1 문의로 연락주세요.

접수 시 알려주실 내용:
  • 주문번호
  • 불량 증상 설명
  • 가능하면 사진 또는 영상 첨부

제품 하자 확인 시 무상 교환 처리해드립니다. 왕복 배송비는 저희가 부담합니다.
고객님의 불편을 최소화하기 위해 최대한 빠르게 처리해드립니다. 3시간 이내 답변 드리겠습니다.
▶ AS(수리)는 가능한가요? AS
네, AS 접수 가능합니다.

  • 1:1 문의 또는 카카오채널로 주문번호 + 증상 접수
  • 보증 기간 내 제조상 결함 → 무상 수리/교환
  • 보증 기간 외 또는 사용자 과실 → 유상 수리 (비용 사전 안내)

자세한 보증 정책은 제품 동봉 보증서를 확인해주세요.
▶ 환불은 언제 되나요? 환불
반품 제품 입고 확인 후 영업일 기준 3~5일 이내 환불 처리됩니다.

  • 카드 결제: 카드사에 따라 2~5 영업일 내 취소 반영
  • 무통장 입금: 환불 계좌로 직접 입금

환불 처리 완료 시 안내 문자를 보내드립니다.

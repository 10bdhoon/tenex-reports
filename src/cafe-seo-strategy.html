1 CONTENT

SEO 콘텐츠 분류 — 4분류에서 6분류로

처음 제안한 4분류는 "누가 쓰냐"로만 나뉘어 있었다. 발신자에 전문가(권위) 축을, 콘텐츠 성격에 비교/추천 축을 더해 6분류로 확장.

처음 제안한 4분류

  • ① 1분도수가 주는 정보성 콘텐츠
  • ② 1분도수가 주는 운동정보 + 후기 섞인 콘텐츠
  • ③ 고객들이 쓰는 정보성 콘텐츠
  • ④ 고객들이 쓰는 후기성 콘텐츠
빠진 것 → ① 검색의도 축(증상·솔루션·비교) · ② 전문가 권위 콘텐츠(3중 타인증명의 권위 축) · ③ 플랫폼별 전략

2 SEARCH INTENT

검색의도 3단계 — 사람은 단계별로 다르게 검색한다

SEO는 결국 "누가 쓰냐"가 아니라 검색의도로 먹는다. 구매 퍼널 단계별로 콘텐츠를 배치.

증상 검색

"목 통증", "거북목 자가진단" — 문제 인식 단계. ①③이 커버.

솔루션 검색

"거북목 교정 효과", "목 견인 원리" — 해결책 탐색. ①②⑥이 커버.

비교·구매 검색

"목 마사지기 추천", "OO vs OO 후기" — 구매 직전. ⑤가 커버. 전환율 최고 구간.

3 REPURPOSING

유튜브 재가공 파이프라인 — 1영상을 검색 자산 4배로

영상 1개를 "콘텐츠 1개"로 보지 않는다. 텍스트·이미지·숏폼으로 분해해 검색 표면적을 늘린다. 제작비 0원으로 SEO 자산 3~4배.

  • 유튜브 자체 SEO — 대본을 자막으로 넣으면 구글·유튜브가 영상 내용을 텍스트로 색인. 유튜브는 구글 검색결과에도 직접 노출.
  • GIF/캡쳐 + 글 — "원리 설명" 장면을 GIF로, 대본을 글로 풀어 카페·지식인 답변에 첨부. 영상보다 검색 체류·인용에 강함.
  • 숏폼 분해 — 긴 영상 → 30초 클립 여러 개. 각각 다른 키워드 타게팅.
  • 인터뷰 영상 — 고객 인터뷰(촬영 완료분)는 ④후기 + ⑥권위 동시 자산. 카페(가두리 충성) + 유튜브(검색 유입) 양쪽에 배치.
블로그 SEO를 안 하므로, 글 변환물의 착지점은 블로그가 아니라 카페 글·지식인 답변·상세페이지 FAQ가 된다.
4 CHANNELS

채널 3축 — 블로그는 일단 제외

블로그 SEO에 집중하지 않기로 결정. 남은 3축으로 역할을 분담한다.

유튜브

정보·권위 콘텐츠 본진. ①②⑥ + 숏폼 분해.

카페 / 지식인

UGC 후기·질문답변으로 검색 상단 장악. ③④ + 유튜브 재가공 글/GIF.

상세페이지

비교표·전문가 소견 = 구매 직전 전환. ⑤⑥.

★ LIVE

주간 라이브 방송 (인규) — 콘텐츠·커뮤니티 엔진

매주 정기 라이브로 운동을 같이 하고, 제품도 같이 쓴다. 단발 콘텐츠가 아니라 카페·유튜브·후기를 한 번에 돌리는 리듬 엔진. (※ 별도 채널이 아니라 모든 축을 관통하는 핵심 자산이라 ★로 표기)

① 커뮤니티 리듬 · 리텐션

  • 매주 같은 시간 모임 = 소속감·습관 형성
  • 라이브 참여를 카페 등급·가두리와 결합 → 참여가 곧 충성 지표
  • 운동 인증·숙제를 카페에 올리게 → 후기·게시물 자동 생산

② 실시간 제품 체험 → 후기

  • 같이 쓰면서 자연스러운 실사용 후기 유발 (④ UGC 소스)
  • 라이브 커머스로 구매 전환 직접 연결
  • 인규(크리에이터 IP) + 치료사 협업 운동 = 권위 결합
라이브 1회 = 재가공 파이프라인의 최상위 소스. 다시보기 → 숏폼·GIF·대본글로 분해해 유튜브·카페·상세페이지로 착지(↑ 유튜브 재가공과 직결). 정기성(매주)이 검색·알고리즘·습관 셋 다 먹는 핵심.
5 CAFE STRATEGY

네이버 카페 전략 종합

검색 유입(공개)과 충성·전환(가두리)을 한 카페 안에서 의도적으로 분리한다.

① 구조 — 공개 ↔ 가두리 이원화

  • 공개 게시판 : 정보성(①③)·비교추천(⑤) → 구글·네이버 검색 유입용
  • 가두리(등급 제한) : 후기·등급 혜택·자랑질·전용 콘텐츠 → 충성·전환용
  • 원칙 → 공개 = 유입 / 폐쇄 = 충성

② 등급제 = 후기 생산 엔진

  • 등급업 조건에 "실사용 후기 작성" 박기 → 명예욕이 UGC를 자동 생산
  • 등급별 차등 : 전용 콘텐츠·할인·신제품 우선체험
  • "이달의 후기" · "명예의 전당" = 자랑질 무대
  • 후기 "유도"가 아니라 시스템으로 강제하는 설계

③ 시딩 → 자연발생 전환

  • 초기 : 1분도수 직접 + 고객후기 직접 시딩
  • 티핑포인트 설정 — 자연발생 후기가 일정 비율 넘으면 직접 까기 축소
  • 안 그러면 "계속 우리가 까는 카페"로 남음

④ 원청 의료기기 신뢰 레버리지

  • 제품은 전부 일반 공산품 — 단, 의료기기의 원리를 그대로 구현
  • 그 원리의 원청 의료기기가 6월 출시 → "이 기술의 원조는 의료기기" 권위 백업
  • ⑥ 전문가 콘텐츠와 묶어 "검증된 원리" 서사
6 GAPS

실행 전 메꿀 구멍 3개 — 현재 상태

전략 뼈대는 완성형. 실행 전에 메꿔야 할 구멍 3개와 그 해소 현황.

✓

① 카피 가이드라인 (법적 리스크)

일반 공산품은 의료적 효능 주장 자체가 불법 — "치료·교정·혈액순환 개선" 사용 시 무허가 의료기기 오인광고(의료기기법 위반). "의료기기 원리로 만든" 표현도 오인 소지.

해소 — 우린 원래 효능 단정 안 함. 단, 시딩 후기에서 고객이 무심코 "치료됐다" 쓰는 건 한 번 걸러야 함. 카피는 "시원함·이완·사용감" 체감 표현으로.

✓

② 카페 콜드스타트 (초기 회원)

등급제·자랑질은 사람이 모인 뒤 작동 — 회원 50명일 땐 "명예의 전당"이 안 굴러간다.

해소 — 유튜브·인스타로 사람 모으면 초기 500명은 순식간(콘텐츠 하나로 수십만 도달). 안 되면 메타광고. 부트스트랩 채널 확보됨.

~

③ 측정 / KPI

기준 데이터가 없어 절대 목표를 못 세우는 상태.

진행중 — 앳홈 속도 벤치마크 추종 + 네이버 카페 강사 미팅으로 베이스라인 확보 예정. (상세 ↓ 7번)

7 KPI

KPI — 기준 데이터가 없을 때

절대 목표를 못 세우면 상대 속도(벤치마크 추종)로 간다. 단 두 가지 함정 주의.

함정 1 — "회원수 추종"
앳홈을 따라갈 때 회원수만 보면 안 된다. 죽은 회원 1만 명 < 후기 까는 500명. SEO·전환에 먹히는 건 활성도. 벤치마크도 가능하면 글/후기 생산량으로 본다.

0→1 단계 KPI = "장악"이 아니라 "엔진 작동 확인"

기준 데이터 없는 초기엔 결과(매출 전환)가 아니라 선행지표를 본다. 이게 돌면 회원수·매출은 따라온다.

  • 후기 생산율 — 가입자 대비 후기 쓴 % (등급제가 실제로 UGC를 뽑아내나? 0이면 전략 자체가 안 도는 것)
  • 등급 상승률 / 재방문율 — 가두리·명예욕이 작동하나?
  • 후기 1건당 검색 노출 수 — SEO로 전환되나?
벤치마크 대상 앳홈 속도 정도는 따라가는 것을 목표로. 회원수가 아닌 활성도(게시물·후기 생산량) 기준으로 추종.
8 DECISION

대표카페 vs 브랜드카페 — 대표카페로 간다

브랜드카페는 대표카페 지정을 못 받는다. 목표가 "SEO 장악"이면 답은 거의 정해져 있다.

브랜드카페

  • 신규 유입 약함 (브랜드명 알아야 검색)
  • 대표카페 지정 불가
  • SEO 장악 불가
  • 통제·브랜드자산은 강함

대표카페 (주제형)

  • 주제 키워드 검색 상단 고정 노출
  • 신규 유입 강함 = 검색 장악
  • "거북목·자세교정" 등 주제 단위로 독점
  • SEO 장악의 핵심 무기
정정 — 1분도수는 "제품 브랜드"가 아니라 "콘텐츠 IP"다.
나이키 공식카페와 다르다. 1분도수는 이미 도수운동 주제의 권위 크리에이터라, 브랜드 = 주제 그 자체. 따라서 콘텐츠·운동법(치료사 협업)은 진하게 가도 OK — 오히려 대표카페에 유리. 절제할 건 브랜드색이 아니라 제품 판매(CS-25/ES808) 도배뿐.

함정 1 — 상업성 박탈

네이버는 대표카페를 "주제 중립·정보 풍부" 카페에 준다. 제품 판매 도배 시 상업카페로 보고 지정 안 하거나 박탈. → 콘텐츠는 진하게, 제품 커머셜은 절제.

함정 2 — 선점 경쟁

핵심 키워드는 이미 누가 먹고 있을 수 있음. 시작 전 타겟 키워드 대표카페 선점 현황 조사 필수.

통제 문제는 역할 분리로 해결 — 카페 = 주제형 대표카페(SEO·UGC·커뮤니티) / 자사몰·인스타·유튜브 = 브랜드 통제·공식 메시지·전환. 카페로 모아 → 가두리로 충성 → 자사몰로 전환.
9 COMPETITION

경쟁 돌파 — "숲 등급" 선점 카페를 어떻게 이기나

타겟 키워드는 이미 선점된 상태. 경쟁 카페는 네이버 숲 등급(카페 최고 등급)이며, "순수 정보 커뮤니티의 탈"을 썼지만 실제론 바이럴 업체가 글을 대량으로 올리는 위장 상업카페다.

규모로 선 카페는 규모로 못 이긴다. 후발이 대형 종합카페를 회원수·누적글로 정면 추월하는 건 거의 불가능. → 게임을 바꾼다.

① 질로 차별화

그들 = 텍스트 종합 커뮤니티. 우리 = 1분도수 영상 IP + 치료사 협업 + 실제 체험·인터뷰. "더 큰 도수카페"가 아니라 "질이 다른 미디어형 카페".

② 롱테일 다수 장악

대표카페는 키워드별 지정. 세부(롱테일) 키워드부터 잡아간다 → 완전 메인 키워드는 나중. 넓은 키워드("도수치료") 정면승부 ✕ → "1분 도수운동·셀프 도수·거북목 1분운동" 등 좁은 키워드 다수 먼저 선점 ✓. 권위·트래픽 쌓인 뒤 메인 키워드로 확장.

③ 신생 키워드 선점

이미 선점된 키워드 탈환은 비용 큼. 차라리 아직 대표 없는 신생 키워드 선점이 빠를 수 있음.

위장 상업카페라는 점이 오히려 기회다. 그들이 바이럴 업체 글로 도배된 카페라면, 우리는 진짜 정보·진정성·검증된 콘텐츠 IP로 차별화할 여지가 크다. 정면충돌이냐 공존이냐는 그들의 성격(정보형 vs 경쟁제품 푸시형)에 따라 갈림 → 위장 상업카페로 확인됨.
10 ASK THE EXPERT

강사 미팅에서 캐올 질문

막연히 "이기는 법"이 아니라 숫자·사례로 캐온다. 이게 KPI 베이스라인도 된다. (네이버 카페 교육 + 오프라인 강사 미팅)

비슷한 규모 카페의 가입 후 첫 글 작성 전환율이 보통 몇 %냐? → KPI 베이스라인 확보

대표카페 지정·박탈 실제 기준은? (글 수·회원 활성도·상업성 판단선) → 우리 대표카페 노선의 핵심

초기 직접 시딩 비율을 보통 어디까지 가져가냐? → 시딩→자연발생 티핑포인트 설정

숲 등급 선점 카페를 후발이 이긴 실제 사례가 있냐? 정면이냐 틈새냐? → 경쟁 돌파 전략 검증

이미 대표카페 지정된 키워드를 뺏는 게 가능하냐, 아니면 새 키워드 키우는 게 빠르냐? → 탈환 vs 신생 선점 의사결정

우리처럼 영상 IP가 강한 카페가 종합카페 대비 먹히는 차별화 포인트는? → 질적 차별화 무기 검증

실행 우선순위

  • 1. 세부(롱테일) 키워드부터 선점 조사 — 대표카페 노선의 출발점. 완전 메인 키워드는 나중, 세부부터. "셀프 도수·거북목 1분운동·1분 도수운동" 등 좁은 후보를 좁히고 각 키워드 대표카페 선점 여부 확인.
  • 2. 주간 라이브(인규) 정례화 — 매주 운동+제품 사용 라이브를 콘텐츠·커뮤니티 엔진으로 가동. 라이브 → 재가공 → 카페 착지 루프.
  • 3. 강사 미팅 — 위 6개 질문으로 베이스라인·박탈 기준·탈환 가능성 확보.
  • 4. 카피 가이드라인 1page — 시딩 후기 검수 기준(효능 단정 필터) 문서화 후 시딩 시작.
  • 5. 콜드스타트 실행 — 유튜브·인스타 → 카페 유입 동선 + (백업) 메타광고.
요약 — 네 4분류 → 6분류 + 채널 3축 + 주간 라이브 엔진 + 재가공 파이프라인 + 대표카페 노선 + 경쟁 돌파(질·롱테일·신생키워드). 키워드는 세부 먼저 → 메인 나중. 실행 전 카피 가이드라인부터.

KEY FEATURES
🎯
보유 기기 맞춤 루틴
CS-25 / ES-808 / WS-200 조합에 따라 완전히 다른 루틴 생성. 없는 기기는 제외하고 최적 조합으로.
📊
통증 강도 반응형 강도 조절
슬라이더 값에 따라 기기 세기, 사용 시간, 운동 난이도 자동 조정. 통증이 심할수록 회복 → 교정 비중 증가.
🤖
RAG 기반 전문가 콘텐츠
1분도수 영상 200건+ DB에서 통증 부위에 맞는 영상 자동 매핑. 물리치료사 감수 콘텐츠만 사용.
📈
AI 회복 예측
루틴 수행 시 통증 감소 예상치 제공. 지속 동기 부여 및 이탈 방지 효과.
🔄
전신 확장 구조
목 → 어깨 → 허리 → 손목. Phase 2에서 전신 루틴으로 확장. 기존 데이터 그대로 활용.
💡
운동-회복-교정 3단계 루틴
키네메디칼 4단계 솔루션(운동-회복-교정-고정)을 앱으로 구현. 기기별 역할을 루틴 안에 자연스럽게 녹임.
VALUE PROPOSITION
80%
기기 방치율 (해결 대상)
구매자 10명 중 8명이 기기를 방치한다. 앱은 이 80%를 매일 쓰게 만드는 유일한 수단. 방치 = 재구매 없음 = 성장 한계.
30%
2일 연속 수행 시 통증 감소 예측
AI가 생성하는 즉각적인 피드백. "2일만 하면 30% 줄어든다"는 메시지가 이탈률을 낮추고 루틴 지속을 유도.
3개월
ML 경쟁 해자 형성 시점
3개월치 개인 데이터가 쌓이면 경쟁사가 복제 불가능한 개인화 수준 달성. 데이터 = 진입장벽 = 기업가치.
200건
RAG 기반 전문가 콘텐츠 DB
1분도수 채널 영상 200건+를 AI가 실시간 검색해 루틴에 삽입. 콘텐츠 채널이 앱의 핵심 경쟁력으로 전환.

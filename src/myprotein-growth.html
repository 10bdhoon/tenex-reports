올리버 쿡슨(Oliver Cookson)이 £500으로 시작해 세계 #1 온라인 스포츠 영양 브랜드를 만든 여정
"저는 할머니가 남겨주신 £500 유산과 중고 제과 장비로 시작했습니다. 창고가 제 침실이었고, 포장은 제 손으로 했습니다."
— Oliver Cookson, Myprotein 창업자 (The Times, 2011)
2004
창업 — "침실에서 시작한 단백질 가게"
맨체스터 대학 중퇴 후 Oliver Cookson이 할머니 유산 £500으로 단백질 보충제 온라인 판매 시작. 맨체스터 소재 창고를 직접 운영. myprotein.com 도메인 등록 후 자사몰 D2C 모델로 론칭. 핵심 초기 제품: 웨이 프로틴 파우더.
D2C 처음부터 선택 — 마켓플레이스 없음
2004~2008
초고속 성장 — SEO + 가격 경쟁력
Google Shopping 초기 진입자 이점 활용. 경쟁사보다 30~50% 저렴한 가격으로 급성장. 영국 내 온라인 스포츠 영양 시장 점유율 빠르게 확대. 전통 보충제 브랜드들이 오프라인 중심일 때 온라인 독점 포지셔닝.
온라인 선점 + 최저가 = 빠른 시장 장악
2008~2010
유럽 확장 & 인플루언서 프로그램 시작
독일, 프랑스, 스페인 등 유럽 주요 시장 진출. 현지화된 별도 사이트 운영. 피트니스 블로거·유튜버에게 제품 지급 + 커미션 코드 제공하는 어필리에이트 프로그램 도입 (지금의 인플루언서 마케팅 원형). Bodybuilding.com 등 커뮤니티 플랫폼 공략.
인플루언서 마케팅 선구자 — 2010년 이전부터
2011년 6월
THG(The Hut Group) 인수 — £58.4m
영국 이커머스 그룹 THG가 마이프로틴을 £58.4m(약 800억원)에 인수. 당시 창업 7년 만의 엑싯. THG의 물류·테크 인프라를 활용한 글로벌 확장 가속화. Oliver Cookson은 일정 기간 경영 참여 후 퇴사.
£500 → £58m: 7년 만에 116,000배 성장
2014
법적 분쟁 & 브랜드 확장
THG가 Oliver Cookson 상대 £1500만 소송 제기(인수 전 이익 과장 주장). 쿡슨 역소송 £1270만. 런던 고등법원 판결: 쿡슨 净 £650만 승소. Myvitamins 브랜드 론칭으로 영양제 카테고리 확장. 브랜드 패밀리 전략 시작.
2015
美 켄터키 생산기지 — $1700만 투자
미국 켄터키주 불릿카운티에 첫 해외 생산·물류 시설 투자($17m). 350개 신규 일자리 창출. 북미 시장 공략을 위한 현지 생산·배송 체계 구축. Myvegan 브랜드 론칭으로 식물성 시장 진출.
미국 현지화 = D2C 물류 내재화
2017~2019
아시아 진출 & MP Activewear 론칭
중국 티몰(Tmall) 글로벌 입점으로 아시아 진출. 한국, 일본, 싱가포르 등 아시아 시장 별도 사이트 운영. MP Activewear 론칭으로 스포츠 의류 카테고리 추가. THG Ingenuity 플랫폼을 통한 자체 기술 역량 강화.
2020년 9월
THG 런던증시 IPO — 기업가치 £54억
THG plc가 런던증권거래소 상장. IPO 주가 £5.40, 기업가치 £54억(약 8조원). Myprotein은 THG Nutrition 세그먼트의 핵심 브랜드. 상장 후 디지털 마케팅 및 글로벌 인프라 추가 투자.
세계 최대 온라인 스포츠 영양 브랜드 공식 인정
2022~현재
구조조정 & 오프라인 채널 추가
THG 주가 하락으로 Ingenuity 사업부 분리 결정. THG = Beauty + Nutrition 두 핵심 축으로 재편. Myprotein은 선택적 오프라인 유통(Boots, Amazon 등) 병행. 구독 모델 강화로 LTV 향상 집중.

인플루언서 발굴 — 어떻게 찾았나
초기 (2008~2012): 수동 아웃리치. 마이프로틴 담당자가 직접 피트니스 블로거·초기 유튜버들에게 이메일·DM 발송. "우리 제품 써봐. 코드 줄게." 수십 명 단위로 시작.

중기 (2012~2016): 셀프서비스 신청 폼 오픈. myprotein.com에 "Ambassador Application" 페이지 개설. 이름, SNS 계정, 팔로워 수, 콘텐츠 유형 입력 → 1~2주 내 심사 → 이메일로 승인/거절 통보. 신청 폼이 생기자 인플루언서들이 알아서 몰려왔다.

후기 (2016~현재): 바이럴 자체 성장. 기존 앰배서더가 피트니스 커뮤니티에서 코드 쓰는 모습을 보고 다른 크리에이터들이 스스로 신청. "나도 MP 앰배서더야"가 피트니스 인플루언서의 배지가 됨. 별도 모집 없이도 자동 유입.
수동 DM → 자동화 폼 → 바이럴 전용 랜딩페이지 필수
02
심사 기준 — 누구를 뽑았나
최소 팔로워: 1,000명 (진입 장벽을 낮춰 최대한 많이 모집).
심사 항목: 피트니스/영양/건강 관련 콘텐츠 비율, 팔로워 참여율(좋아요/댓글), 이미지 품질, 이전 브랜드 파트너십 여부.

팔로워 수보다 적합성 우선: 팔로워 50만인 연예인보다 팔로워 5천인 진짜 피트니스 트레이너를 선호. 타깃 오디언스 일치가 전환율에 직결됨.

자동 거절 기준: 비관련 콘텐츠(요리, 패션만), 낮은 참여율(좋아요 0.5% 미만), 스팸성 계정.
팔로워 수 < 관련성 · 참여율
03
온보딩 프로세스 — 승인 후 뭘 받나
승인 이메일에 포함되는 것:
① 개인 할인 코드 — "SARAH25" 형식 (이름 기반, 기억하기 쉽게). 팔로워에게 공유하면 25% 할인 적용.
② 브랜드 에셋 킷 — 고화질 제품 사진, 로고, 컬러 가이드. 콘텐츠 제작에 바로 사용 가능.
③ 앰배서더 대시보드 접속 — 실시간으로 클릭 수, 주문 수, 누적 커미션 확인 가능.
④ 제품 무료 지급 — 마이크로 앰배서더는 월 £30~50 상당 제품 크레딧. 매크로 이상은 전액 무료 제품 월 발송.
⑤ 콘텐츠 가이드라인 문서 — 필수 사항/금지 사항 명시.
대시보드 = 투명성 = 신뢰 = 동기부여
04
기술 구현 — 코드 시스템이 어떻게 작동하나
할인 코드 발급: 이커머스 시스템(THG Ingenuity)에서 앰배서더별 고유 코드 생성. 코드 → 앰배서더 ID 매핑 DB 유지.

추적 방식: 코드 입력 시 → 주문에 코드 ID 태깅 → 앰배서더 계정에 실적 집계. 쿠키 기반 추적(30일 쿠키)으로 코드 입력 없이 링크로 들어온 경우도 추적.

어필리에이트 플랫폼: 초기에는 자체 시스템, 규모 커지면서 Rakuten Advertising, 이후 Impact.com 등 전문 어필리에이트 플랫폼 연동. 플랫폼이 자동으로 커미션 계산·정산 처리.

대시보드 데이터: 총 클릭 수, 전환율, 주문 금액, 누적 커미션, 이번 달 실적 — 앰배서더가 실시간 확인 가능. 이게 없으면 앰배서더가 콘텐츠를 만들 동기가 없다.
고유 코드 = 추적 = 정산 대시보드 없으면 반쪽짜리
05
콘텐츠 가이드라인 — 자유 vs 통제
철학: "자유롭게, 하지만 선 넘지 마라."

✅ 권장 (자유):
· 자신만의 스타일로 제품 사용 후기 작성/촬영
· 레시피, 운동 루틴, 다이어리 형식 등 포맷 자유
· 솔직한 개인 의견 표현 (쓴소리도 OK)
· 스토리, 릴스, 유튜브 영상, 블로그 포스팅 모두 OK

❌ 금지 (레드라인):
· 경쟁사(GNC, Optimum Nutrition 등) 직접 비방 금지
· 의학적 효능 과장 클레임 금지 (규제 이슈)
· 브랜드 로고 무단 변형 금지
· #ad / #gifted / #sponsored 미표시 금지 (ASA 규정)

결과: 인플루언서가 자기 목소리로 콘텐츠를 만들기 때문에 광고처럼 보이지 않고 신뢰도 높은 추천이 된다. 브랜드가 만든 광고보다 훨씬 효과적.
06
커미션 구조 & 정산 — 돈은 어떻게 줬나
티어별 커미션:
티어 팔로워 수 커미션율 제품 지원 추가 혜택
마이크로 1K ~ 10K 10% 월 £30~50 크레딧 개인 코드
라이징 10K ~ 100K 15% 월 제품 무료 발송 코드 + 링크
매크로 100K ~ 1M 20% 전품목 무제한 전담 매니저 배정
엘리트 1M+ 고정 계약 + % 전품목 + 공동개발 독점 제품 기회
정산 주기: 월 1회, 최소 지급 기준 달성 시(£50 이상) 은행이체 또는 PayPal로 자동 지급.
추적 기간: 쿠키 30일 — 코드 클릭 후 30일 내 구매 시 해당 앰배서더 실적으로 인정.
07
스케일 방법 — 50명에서 10,000명으로
Phase 1 (2008~2011): 시드 50~100명
수동으로 영국 피트니스 블로거/유튜버 50~100명 직접 섭외. 이들이 코드를 공유하면서 브랜드 인지도 생성.

Phase 2 (2012~2015): 셀프서비스 → 1,000명
신청 폼 오픈. 기존 앰배서더가 커뮤니티에서 "나 MP 앰배서더야"라고 하면 다른 크리에이터들이 신청. 월 수백 명씩 신규 유입. 심사 자동화(최소 기준만 충족하면 자동 승인).

Phase 3 (2015~2020): 글로벌 확장 → 10,000명
국가별 현지 앰배서더 모집. 독일, 스페인, 미국 등 각 지역 피트니스 인플루언서 별도 공략. THG 인수 자금으로 전담 팀 구성. 앰배서더 관리 플랫폼(Impact.com 등)으로 운영 자동화.

핵심 인사이트: 진입 장벽을 낮추고(팔로워 1000명), 대시보드로 투명성을 높이고, 제품을 무료로 줬더니 앰배서더들이 알아서 성장을 만들었다. 브랜드는 시스템만 관리.
⚡ 공구 vs 마이프로틴 어필리에이트 — 왜 다른가
항목 🇰🇷 한국식 공구 마이프로틴 어필리에이트
일정 특정 기간 한정 ("7/1~7/7 공구") 상시 운영 — 365일 언제든 추천 가능
콘텐츠 주체 브랜드가 기획한 공구 템플릿 사용 인플루언서가 자기 스타일로 알아서 제작
코드 공유 방식 같은 링크/코드를 여러 명이 공유 각자 고유 코드 — "SARAH25"는 Sarah만 씀
관리 부담 브랜드가 매번 기획·진행·마감 시스템이 알아서 추적·정산 — 브랜드는 모니터링만
인플루언서 동기 일회성 계약 → 끝나면 다음 브랜드로 상시 수익 → 오래 써줄수록 본인에게 이익
스케일 동시 관리 인플루언서 수십 명이 한계 시스템화로 10,000명+ 동시 운영 가능
신뢰도 "광고" 느낌 강함 (공구 = 돈 받고 파는 것) 일상 콘텐츠 속 자연 노출 = 신뢰도 높음
결론: 마이프로틴이 만든 건 "공구 시스템"이 아니라 "자생적 판매 네트워크"다. 인플루언서가 자기 이익을 위해 자발적으로 콘텐츠를 만들고, 그게 자동으로 매출로 연결된다. 브랜드는 시스템을 만들고 제품을 공급할 뿐.

STEP 1 · 즉시 (1주 내)
카페24 할인코드 시스템 세팅
카페24 지원 여부: ✅ 가능
카페24 어드민 → 프로모션 → 쿠폰 관리 → "코드 쿠폰" 생성.

설정 방법:
· 쿠폰 코드: "DRKIM15" (앰배서더 이름 기반)
· 할인율: 15% (ES-808 단가 고려)
· 사용 횟수: 무제한 (1인 1회 사용은 X)
· 유효기간: 6개월 갱신 방식
· 적용 상품: ES-808 + 크림 지정

⚠️ 한계: 카페24 기본 쿠폰은 "어떤 코드가 몇 번 사용됐는지" 추적은 되지만 주문별 매칭 보고서가 약함. 엑셀로 수동 관리하거나 카페24 API로 주문 데이터 추출 필요.
→ 카페24 쿠폰 관리에서 코드 5개 먼저 생성
STEP 2 · 1~2주
어필리에이트 랜딩페이지 제작
마이프로틴처럼 "앰배서더 신청 페이지"가 있어야 한다.

포함 내용:
· 프로그램 소개 (코드 주면 팔로워 15% 할인, 나는 판매액 10% 수령)
· 신청 폼: 이름, 직업(물리치료사/PT/크리에이터), SNS 링크, 팔로워 수, 추천 이유
· 예상 수익 계산기 (팔로워 1만 명에 전환율 1% → 월 판매 100개 → 커미션 ○○만원)

호스팅: 카페24 기본 페이지 또는 별도 랜딩페이지 툴(Framer, Notion).
→ 랜딩페이지 초안 하루면 만들 수 있음
STEP 3 · 2~4주
시드 앰배서더 10명 직접 섭외
마이프로틴도 처음엔 수동 DM. 자동화는 나중 일.

타깃 목록 (우선순위 순):
1. 1분도수 수강생 중 SNS 활동하는 도수치료사
2. 인스타에서 "#물리치료사" "#도수치료" 검색 → 팔로워 1천~1만 사이 계정
3. 유튜브에서 재활/통증 콘텐츠 크리에이터
4. 피트니스 PT 중 재활 전문 크리에이터

DM 메시지 (간단하게):
"안녕하세요! 1분도수 키네메디칼입니다. 팔로워분들께 ES-808 15% 할인 드리고, 판매액의 10% 수익을 드리는 앰배서더 프로그램에 관심 있으실까요? 한 달에 ○○만원 추가 수입이 가능합니다."
→ 이번 주 인스타 DM 10건 보내기
STEP 4 · 1개월
온보딩 패키지 & 대시보드 준비
승인 후 앰배서더에게 이메일로 발송:

① 환영 이메일 — 개인 코드 + 사용법
② 브랜드 에셋 — 제품 사진 고화질, 로고 파일
③ 제품 발송 — ES-808 1개 무료 (체험 후 콘텐츠 제작용)
④ 실적 리포트 방식 — 매월 15일에 카카오톡/이메일로 전월 실적 + 정산금 안내

대시보드 현실적 대안:
초기에는 전용 대시보드 개발 불필요. 카페24 API로 쿠폰 사용 내역을 매월 자동 추출 → 구글 시트로 앰배서더별 집계 → 자동 이메일 발송. 앰배서더 수 50명 이상 되면 전용 시스템 투자.
→ 구글 시트 + 카페24 API로 1주 내 구현 가능
STEP 5 · 3개월+
커미션 구조 & 정산 자동화
커미션 제안 (초안):
· 팔로워 1K~5K: 제품 1개 + 판매액 8%
· 팔로워 5K~50K: 제품 + 판매액 10%
· 팔로워 50K+: 제품 + 판매액 15% + 전담 지원
· 의사·물리치료사 자격증 보유자: 팔로워 무관 12% (신뢰도 프리미엄)

정산: 매월 말일, 최소 3만원 이상 발생 시 계좌이체.

한국 어필리에이트 플랫폼 옵션:
· 링크프라이스(Linkprice): 카페24 연동 쉬움
· 쿠팡파트너스: 마켓플레이스 전용이라 부적합
· 셀러허브, 텐핑: 국내 어필리에이트 중간 플랫폼
→ 초기엔 카페24 직접 + 구글 시트로 충분
→ 링크프라이스 카페24 연동 검토
STEP 6 · 6개월+
스케일업 — 자동화 & 바이럴
앰배서더 10명이 자리 잡으면 그다음은 자동화:

신청 자동화: Typeform(또는 네이버폼) 신청 → Zapier로 카페24 쿠폰 자동 생성 → 환영 이메일 자동 발송.

바이럴 장치: "앰배서더 추천으로 앰배서더가 되면 추천인에게 추가 커미션 1%" 레퍼럴 구조 추가.

콘텐츠 가이드: "이런 콘텐츠가 제일 팔렸어요" 월간 뉴스레터 → 잘 팔리는 콘텐츠 포맷을 앰배서더들이 참고하게.

목표: 6개월 내 앰배서더 50명, 1년 내 200명. 200명 × 월 평균 2건 판매 = 월 400건 추가 매출.
→ Zapier 자동화 플로우 설계
⚙️ 카페24 할인코드 시스템 — 기술 구현 가이드
단계 방법 비용 난이도
코드 발급 카페24 어드민 → 프로모션 → 쿠폰 → 코드 쿠폰 생성 무료 쉬움
실적 추적 카페24 API (주문 조회 + 쿠폰코드 필터) → 구글 시트 자동 집계 개발 1~2일 중간
커미션 계산 구글 시트 수식 자동화 (쿠폰 코드별 매출 × 커미션율) 무료 쉬움
정산 알림 구글 앱스크립트 → 매월 말 앰배서더에게 이메일/카톡 자동 발송 무료 중간
앰배서더 대시보드 구글 시트 공유 (개인 시트 탭) 또는 전용 Notion 페이지 무료 쉬움
자동화 (스케일업) 링크프라이스 카페24 연동 또는 Refersion 등 SaaS 툴 월 $50~200 플러그인
💡 핵심 요약 — 스미스 멘토가 말한 "마이프로틴을 보라"의 의미
마이프로틴이 만든 건 "광고 캠페인"이 아니라 "자생적 판매 인프라"였다.
물리치료사가 환자에게 "저도 이거 써요. 제 코드 쓰면 15% 싸요"라고 하면 → 그게 가장 강력한 광고다.
전문가의 추천 + 할인 혜택 + 투명한 수익 구조 = 키네메디칼 버전 마이프로틴 앰배서더 시스템.

지금 당장 할 것: 카페24에서 코드 5개 만들고 → 1분도수 수강생 중 SNS 하는 치료사 5명에게 DM 보내기. 나머지는 그다음.
🎯 키네메디칼 시사점 — 우리가 배울 것
마이프로틴 성장 공식을 D2C 의료기기/건강기기 브랜드에 적용하는 방법
시사점 01
🤝 인플루언서 앰배서더 시스템 구축
마이프로틴은 팔로워 1,000명부터 신청받아 10,000+ 앰배서더 제국을 만들었다. 1분도수 시청자 중 피지오·재활 전문가, 피트니스 트레이너, 건강 크리에이터를 타깃으로 앰배서더 프로그램 운영. 제품 제공 + 할인 코드 + 커미션 구조로 입소문 마케팅 시스템화.
→ ES-808 앰배서더 프로그램 설계 필요
시사점 02
📝 콘텐츠 → 신뢰 → 구매 퍼널
마이프로틴의 "The Zone"처럼, 1분도수 유튜브·블로그가 이미 신뢰 콘텐츠 역할을 하고 있다. 목·허리 디스크 회복 가이드 → ES-808 소개 → 구매 흐름. SEO 최적화된 통증 관련 아티클/영상이 광고 없이 고객을 유입시키는 구조.
→ 키네메디칼 콘텐츠 허브 강화 (유튜브 중심)
시사점 03
💰 가성비 포지셔닝 + 세일 전략
마이프로틴은 "저가"가 아닌 "최고 가성비"로 포지셔닝했다. ES-808이 의료기기 시장에서 경쟁사 대비 합리적 가격임을 명확히 소구. 기념일·시즌 세일, 번들 패키지(ES-808 + 글루코사민 크림 등)로 객단가 향상과 유입 증가 동시 달성.
→ 번들 패키지 + 시즌 세일 기획
시사점 04
📧 이메일·CRM으로 LTV 극대화
마이프로틴의 핵심 수익원은 재구매. 구매 후 30일, 60일에 소모품(크림·액세서리) 재구매 유도 이메일 자동화. ES-808 구매자 → 글루코사민 크림 → 앱 구독 → 상위 제품으로 업셀링하는 CRM 플라이휠 설계.
→ 구매 후 CRM 시퀀스 설계 강화
시사점 05
🏭 자체 제조 = 원가 경쟁력의 핵심
마이프로틴이 경쟁사보다 30~50% 저렴할 수 있었던 이유는 자체 생산. 키네메디칼도 OEM 의존을 줄이고 주요 제품의 자체 설계·생산 비중을 높일수록 가격 경쟁력과 마진이 동시에 향상된다.
→ 핵심 제품 자체 설계·IP 강화
시사점 06
🌏 단계적 글로벌 확장 공식
마이프로틴: 영국 1위 → 유럽 → 북미 → 아시아. 키네메디칼: 한국 1위 → 일본/대만 → 동남아 → 북미. 각 단계에서 현지 인플루언서 선확보 후 시장 진입. 글로벌 스미스(Smith) 멘토 조언처럼 마이프로틴 공식을 따라가면 된다.
→ 일본·대만 현지 피지오 인플루언서 섭외 우선
시사점 07
🔁 브랜드 패밀리 확장 전략
마이프로틴은 Myvitamins, Myvegan, MP Activewear로 확장했다. 키네메디칼도 ES-808(전기자극) → 도수 기기 → 글루코사민 제품 → 재활 운동 앱으로 "근골격 회복 생태계"를 구축. 한 고객이 여러 제품을 쓰는 구조가 LTV를 극대화.
→ 키네메디칼 브랜드 패밀리 로드맵 설계
시사점 08
🤖 기술 내재화 — D2C 플랫폼
THG는 Ingenuity라는 자체 이커머스 플랫폼을 만들었다. 단기적으로 카페24 자사몰에 충실하되, 중장기적으로 키네메디칼 전용 앱·멤버십 플랫폼을 강화해 외부 플랫폼 의존도를 줄이는 것이 핵심. 고객 데이터를 자산으로 보유해야 한다.
→ 키네메디칼 앱 + 멤버십 강화 우선
💡 핵심 요약 — 스미스 멘토가 말한 "마이프로틴을 보라"의 의미
마이프로틴의 본질은 ① 처음부터 D2C, ② 인플루언서로 신뢰 구축, ③ 가성비 포지셔닝, ④ 이메일로 재구매 락인이다.
키네메디칼도 1분도수 유튜브(콘텐츠 신뢰)를 기반으로 ES-808(D2C 제품)을 팔고, 도수치료사·재활전문가 앰배서더 프로그램으로 의료계 신뢰를 확보하며, 구독 CRM으로 소모품 재구매를 만드는 구조가 정확히 같은 공식이다.
결론: 마이프로틴이 스포츠 영양 시장에서 한 것을 키네메디칼이 근골격 회복 시장에서 하면 된다.

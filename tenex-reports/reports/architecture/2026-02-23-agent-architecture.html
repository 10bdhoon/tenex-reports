모찌 에이전트팀 구조 (참고)

모찌 에이전트팀 (대규모) ├── 🎯 PM 에이전트 — 태스크 분해, 우선순위, 품질 관리 ├── 👑 리더 에이전트 — 아키텍처 결정, 코드 리뷰 최종 승인 ├── 🖥️ 프론트엔드 에이전트 — UI/UX 개발 ├── ⚙️ 백엔드 에이전트 — API/DB 개발 └── 🔍 리뷰어 에이전트 — 코드 검증, 테스트

Phase구조역할 분리상태

P1 (2주 내)카리나(PM) + 전문 에이전트 2개① 데이터 분석 에이전트 (매출/광고/VOC)
② 개발 에이전트 (앱 코딩/빌드)		계획

7. TASK.md 기반 개발 프로세스 도입 계획

모찌의 에이전트팀이 TASK.md를 기반으로 개발을 진행하는 방식을 테넥스에 적용:

개발 프로세스 (목표)

① 태스크 정의 (TASK.md) └── 태훈이 요구사항 전달 또는 카리나가 분석 후 제안 ② 태스크 분해 (카리나 PM) ├── 서브태스크 목록 생성 ├── 우선순위 + 의존성 정리 └── 예상 공수 산정 ③ 실행 (서브에이전트) ├── 코드 작성 / 데이터 분석 / 리서치 ├── 중간 결과 메인에 보고 └── 완료 시 최종 보고 ④ 검증 (카리나) ├── 코드 리뷰 / 결과물 확인 ├── 테스트 실행 └── 태훈에게 결과 보고 ⑤ 배포 + 기록 ├── PR 생성 + 머지 ├── memory/ 에 작업 기록 └── TASK.md 상태 업데이트

# TASK.md — 진행 중인 태스크 ## 🔴 진행 중 - [ ] VOC 자동 수집 파이프라인 구축 - 담당: 데이터 분석 에이전트 - 의존: Cafe24 게시판 API 문서 확인 - 예상: 3일 ## 🟡 대기 중 - [ ] Supabase pgvector 벡터 DB 구축 - [ ] 콘텐츠 큐레이션 대시보드 MVP ## ✅ 완료 - [x] Cafe24 + Meta Ads API 연동 - [x] 일일 매출 리포트 자동화 - [x] 1분도수 앱 PR #99 (홈 가이드 + 회복점수 + 프로필 + 슬랙)

1. 핵심 요약

테넥스의 모든 비즈니스 데이터(매출, 광고, VOC, 미팅, 콘텐츠)를 수집 → AI 처리 → 지식창고 → 활용 → 재순환하는 자기강화 지식 시스템.

스미스(Smith) 멘토의 QA Helpdesk 순환 파이프라인과 모찌(Mochi)의 RAG 4계층 구조를 키네메디칼 비즈니스에 맞게 재설계.

2. 전체 순환 구조도

① 수집 COLLECT — 데이터 입구 5개 📊 매출 데이터 Cafe24 API (주문/취소/반품) 📈 광고 데이터 Meta Ads API (spend/ROAS/CTR) 🎙️ 미팅/교육 Plaud 녹음 → Gemini 전사 💬 VOC/CS 고객 문의, 리뷰, 반품 사유 📝 콘텐츠 1분도수 유튜브/인스타 성과 ② 처리 PROCESS — AI가 지식으로 가공 ✂️ 청킹 → 📢 임베딩 (Gemini) → 📋 요약 (Claude/Gemini) ③ 저장 STORE — 지식창고 🗃️ 매출/광고 DB (일별 집계) 🧠 지식 벡터 DB (미팅/VOC/콘텐츠 임베딩) 📋 메모리 파일 (MEMORY.md, memory/*.md) ④ 활용 USE — 3가지 방향 💬 일일 리포트 매출/광고/공헌이익 자동 생성 📊 진단 대시보드 제품별/채널별 성과 분석 🤖 팀 슬랙봇 팀원 질문에 지식 기반 자동 답변 ⑤ 순환 LOOP — 생성물이 다시 지식창고로 ↺ 일일 리포트 인사이트 → 재임베딩 ↺ 진단 결과 → 의사결정 기록 → 재학습 ↺ VOC 패턴 → 제품 개선 → 새 데이터 생성

3. RAG 4계층 구조 (모찌 참고 → 테넥스 버전)

모찌(Mochi) 시스템의 RAG 4계층을 키네메디칼 비즈니스에 맞게 재설계한 구조:

Layer 0 — 정적 지식 (Static Knowledge)

모찌테넥스상태
강의 자료, 교재 PDF제품 매뉴얼 (CS-25, ES-808, WS-200)수동 관리
FAQ 데이터베이스고객 FAQ + 반품 사유 패턴미구현
—Cafe24 API 문서, Meta Ads 가이드참고용 보유

Layer 1 — 구조화 데이터 (Structured Data)

모찌테넥스상태
수강생 DB (진도, 과제)매출 DB (Cafe24 주문/취소/반품 일별 집계)운영 중
결제/구독 데이터광고 DB (Meta spend/ROAS/CTR 일별)운영 중
—공헌이익 계산 데이터 (제품별 마진)운영 중
—1분도수 앱 사용자 데이터 (Supabase)운영 중

Layer 2 — 비구조화 지식 (Unstructured → Embedded)

모찌테넥스상태
강의 영상 전사본 → 임베딩미팅 전사본 (Plaud → Gemini) → 임베딩전사만 완료
커뮤니티 질문/답변VOC/CS (고객 문의, 리뷰)미구현
블로그/SNS 콘텐츠1분도수 유튜브/인스타 콘텐츠 메타데이터미구현
—일일 리포트 아카이브 (인사이트 축적)파일 기반

Layer 3 — 실시간 컨텍스트 (Live Context)

모찌테넥스상태
실시간 채팅 컨텍스트태훈↔카리나 텔레그램 대화 컨텍스트운영 중
현재 세션 메모리MEMORY.md + memory/*.md 파일운영 중
—오늘의 매출/광고 실시간 스냅샷Cafe24+Meta 실시간

4. 콘텐츠 큐레이션 대시보드 (목표)

콘텐츠 소재 선정부터 임베딩까지의 파이프라인을 체계화:

콘텐츠 큐레이션 파이프라인 (목표 시스템) ① 수집 — 데이터 소스 자동 스캔 ├── 유튜브 인기 영상 (키워드: 목디스크, 자세교정, 도수치료) ├── 인스타 트렌드 해시태그 ├── 네이버 건강 카테고리 인기글 └── 경쟁사 콘텐츠 모니터링 ② AI 분석 — 자동 평가 ├── 주제 분류 (교정/회복/제품/운동) ├── 키네메디칼 관련도 점수 (0-100) ├── 트렌드 점수 (검색량/조회수 기반) └── 콘텐츠 형태 추천 (숏츠/릴스/블로그/카드뉴스) ③ 중요도 산정 — 우선순위 큐 ├── 관련도 × 트렌드 = 종합 점수 ├── 제품별 매핑 (CS-25, ES-808 등) └── 시즌 가중치 (겨울=찜질, 여름=운동) ④ 선택 — 사람의 최종 판단 ├── 대시보드에서 후보 목록 확인 ├── 승인/거부/수정 워크플로우 └── 주간 콘텐츠 캘린더 편성 ⑤ 생성 — AI 초안 + 사람 편집 ├── Claude/Gemini가 초안 작성 ├── 제품 사용법 연결 (constants/products.ts 참고) └── 1분도수 영상 시나리오 생성 ⑥ 임베딩 — 지식창고 반영 ├── 완성 콘텐츠 → 벡터 DB 저장 ├── 성과 데이터 연결 (조회수, 전환율) └── 다음 큐레이션 피드백 루프

6. 구현 로드맵

Phase 0 — 현재 (완료)

  • Cafe24 + Meta Ads API 연동
  • 일일 매출 리포트 자동 생성 (Render cron → Slack)
  • Plaud 녹음 → Gemini 전사 → 텔레그램 전달
  • 파일 기반 메모리 시스템 (MEMORY.md)

Phase 1 — 단기 (2주)

  • VOC 자동 수집 (Cafe24 게시판/문의 API)
  • 미팅 전사본 자동 임베딩 (청킹 → Gemini embedding)
  • Supabase 지식 벡터 DB 구축 (pgvector extension)
  • 일일 리포트 Telegram 자동 발송

Phase 2 — 중기 (1개월)

  • 키네메디칼 진단 대시보드 (Vercel + Next.js)
  • 콘텐츠 큐레이션 대시보드 (수집→분석→선택→생성)
  • 슬랙봇 — 팀원 질문 RAG 답변
  • 콘텐츠 성과 자동 수집 (유튜브 API)

Phase 3 — 장기 (분기)

  • 순환 파이프라인 완성 — 생성물 재임베딩 자동화
  • AI 콘텐츠 자동 생성 (1분도수 영상 시나리오)
  • 고객 세그먼트별 자동 마케팅
  • 해외(미국) 시장 데이터 파이프라인

01 현재 CS 프로세스 분석
⚠️ 핵심 문제: 현재 CS는 반응형(Reactive)이다. 문의가 와야 대응한다. 선제적 설계가 없다.
현황 진단 (brain.db + 카페24 데이터 기반)
  • 1점 리뷰 6건 전부 미답변 즉시 조치
    3/25 기준 — 관리자 댓글 0건. 잠재 고객이 그대로 이탈 중.
  • WS-200 부정 리뷰 비율 13.3% 위험
    제품별 이슈가 CS 대응 전략에 반영되어 있지 않음.
  • 부정 리뷰 대부분 "불만족" "별로에요" — 이유 불명 주의
    고객 소통 채널(Q&A) 부재. 불만 원인 파악 불가 → 개선 불가능한 구조.
  • 리뷰 #500·#499 — 주문번호만 적은 CS 문의 의도 연락 필요
    리뷰를 CS 채널로 사용하는 고객 존재. 별도 응대 경로 없음.
  • 자동 배송 안내 문자 운영 중 (ES-808 D+14) 진행 중
    CRM 자동문자 시스템 구축됨. 이를 CS 여정에 통합 확장 가능.

02 고객 여정 매핑

주력 제품 ES-808 기준. 구매 → 배송 → 사용 → 재구매/크로스셀 전체 여정.

STAGE 1
🛒 구매 결정
· 광고 클릭 (메타/유튜브)
· 상세페이지 열람
· 리뷰 확인 (150개+)
✨ 리뷰 신뢰도가 전환 결정
⚠️ 1점 미답변 → 이탈
STAGE 2
📦 배송 대기
· 주문 확인 문자 (자동)
· 배송 조회 안내
· 대기 불안 발생
✨ 선제적 배송 안내
⚠️ 배송 지연 문의 폭증
STAGE 3
📬 수령 직후
· 언박싱 경험
· 사용 가이드 확인
· D+1 환영 문자
✨ 첫 사용 성공 = 장기 팬
⚠️ "어떻게 써요?" 최다
STAGE 4
💪 사용 기간
· 1~2주 효과 체감
· D+7 효과 확인 문자
· D+14 크로스셀 CRM
✨ 효과 체감 → 리뷰 유도
⚠️ 불만족 → 부정 리뷰
STAGE 5
⭐ 리뷰/추천
· D+21 리뷰 요청 문자
· 포토 리뷰 인센티브
· 지인 추천 유도
✨ 리뷰 = 다음 고객 전환
⚠️ 유도 없으면 침묵
STAGE 6
🔄 재구매/크로스셀
· ES-808 → CS-25
· +CS-25 → WS-200
· 정기 케어 프로그램
✨ 루틴 완성 = 브랜드 팬
⚠️ 타이밍 놓치면 이탈
📌 크로스셀 원칙: ES-808만 → CS-25 우선 / ES-808+CS-25 → WS-200 / 3개 보유 → 케어 프로그램
03 터치포인트별 감동 포인트
터치포인트현재 상태감동 포인트 (개선안)담당
주문 직후 문자보통"OOO님, 선택 잘 하셨어요. 이제부터 회복이 시작됩니다." — 감정 연결자동
배송 중 안내없음배송 출발 당일 문자 + 예상 도착일 ("내일 만나요!")자동
수령 D+1없음"잘 도착했나요? 처음 사용법 영상 링크" — 첫 성공 경험 설계자동
사용 D+7일부"1주일 써보셨나요? 효과 어떠세요?" — 효과 확인 + 불만 조기 포착자동
D+14 크로스셀진행 중구매 이력 기반 개인화 메시지 (보유 제품에 따라 분기)자동
부정 리뷰 작성무대응24시간 내 공개 댓글 + DM 직접 연락 → 문제 해결 시도사람
1:1 문의 접수미기준접수 즉시 자동 확인 문자 "3시간 내 답변드리겠습니다" + 실제 3시간 내 답변사람+자동
교환/반품 요청수동빠른 처리 + "불편드려서 죄송합니다" 디지털 손편지 or 쿠폰사람
재구매 고객없음"2번째 선택 감사합니다" — 재구매 고객 전용 메시지로 충성도 강화자동

# 제품 따가움 이슈 - 기술 상담 회의록

**날짜:** 2026-02-06  
**참석자:** Speaker 1 (기술), Speaker 2 (제품/기획)  
**주제:** 고객 문의 "따가운 느낌" 원인 분석 및 해결 방안

---

## 📌 문제 정의

고객이 제품 사용 시 "따가운 느낌"을 경험했다고 문자로 문의

---

## 🔍 원인 분석 (Speaker 1)

### 1. 파형(출력 신호) 문제
- **급격한 파형 상승 시 따가움 발생**
  - 0에서 100으로 순간 도달 → 일정 시간(0.5초) 유지 → 자극 지속 → 따가움 발생
  - 천천히 램프업하는 방식과 큰 차이
  - 플랫폼 변화가 심할수록 따가움 증가

- **신호 지속 시간의 영향**
  - 0.1초 이하: 따가움 느끼지 못함
  - 0.2초 이상: 따가움 발생 가능
  - **자사 제품**: 0.5초 정도 신호 지속 → 자극 계속 파고듦 → 따가움
  - **경쟁사(맘다터)**: 짧은 신호(탕탕탕) → 순간 자극만 → 따가움 적음

- **스파크 문제**
  - 급하게 전기력을 키우고 계속 모아서 정리하면 스파크가 계속 튐
  - 순간적으로 툭툭 튀는 설계 vs 올려서 유지하는 설계의 차이

### 2. 피부 상태
- **유분이 많은 피부**: 따가움 덜 느낌
- **건조한 피부**: 따가움 많이 느낌
- → 크림/젤 사용으로 완화 가능

### 3. 출력 강도 비교
- 자사 제품 출력 강도가 경쟁사(남작)보다 3배 정도 더 쎔
- 하지만 경쟁사는 짧은 시간에 신호 → 따가움 못 느낌
- 자사는 신호 지속 → 따가움 발생

### 4. 물리치료실 기기와의 차이
- **물리치료실 기기**: 따갑지 않음
  - 아날로그 트랜스 방식
  - 복잡한 내부 구조 (덩치가 큼)
  - PCB 한 장 가격만 5~6만원
- **자사 제품**: 소형화를 위해 임의적으로 작은 칩에서 출력 생성
  - 같은 출력을 내려면 구조가 복잡해지고 크기 증가

## 💡 해결 방안

### 즉시 실행 가능
1. **크림 증정** (현재 진행 중)
2. **전용 젤 개발** (진행 중)

### 기술적 해결
1. **짧은 신호(탕탕탕) 모드만 사용**
   - 따가운 기능 제거
   - 짧게 치는 기능은 문제 없음
   
2. **손잡이 전류 방지**
   - 팁을 2개로 분리 (현재 적용)
   - 대안 모양 검토 예정 (Speaker 2가 모양 전달 예정)
